## 4. 系统启动流程

> 对应需求规格书 §9

```
main()
 ├─ NVIC_PriorityGroupConfig(Group_4)     # 中断优先级分组
 ├─ delay_init(72)                        # SysTick 延时初始化（72MHz）
 ├─ GENERAL_TIM_Init()                    # TIM2+TIM3 定时器初始化
 ├─ GPIO 复用配置                          # 关闭 PB3/PB4 的 JTAG 功能
 │
 ├─ LED_Init()                            # LED GPIO
 ├─ Beep_Init()                           # 蜂鸣器 GPIO
 ├─ KEY_GPIO_Config()                     # 5个按键 GPIO
 ├─ OLED_Init()                           # OLED I2C 初始化
 ├─ ADCx_Init()                           # ADC1 初始化
 ├─ DS18B20_Init()                        # DS18B20 1-Wire 初始化
 ├─ Relay_Init()                          # 4路继电器全部关闭
 ├─ Servo_Init()                          # 舵机 PWM 初始化
 │
 ├─ OLED_ShowStart()                      # 显示"智能鱼缸系统"（2秒）
 ├─ delay_ms(2000)
 │
 ├─ SysFlag_Init()                        # 加载默认阈值参数
 ├─ RunMode = 0, Alarm_Enable = 1         # 默认自动模式+报警开启
 ├─ FeedCountdown = FeedInterval          # 喂食倒计时初始化
 ├─ Servo_Off()                           # 舵机关闭
 │
 ├─ OLED_ShowMainPage()                   # 进入主页面
 │
 └─ while(1){ }                           # 主循环（所有逻辑在中断中执行）
```

## 5. 定时器调度机制

> 对应需求规格书 §8

中断源：TIM2（1ms 周期），在 `stm32f10x_it.c` 的 `TIM2_IRQHandler` 中调度。

```
TIM2_IRQHandler (每1ms触发)
 ├─ Timing_1ms()          # 1ms 必执行
 │   ├─ BEEP_DrvScan()    # 蜂鸣器状态机
 │   ├─ LED_DrvScan()     # LED 闪烁状态机
 │   └─ KEY_DrvScan()     # 按键扫描（消抖+长按检测）
 │
 ├─ if(msCnt%2==0)   Timing_2ms()     # 空
 ├─ if(msCnt%5==0)   Timing_5ms()     # 空
 ├─ if(msCnt%10==0)  Timing_10ms()    # 传感器采集
 ├─ if(msCnt%50==0)  Timing_50ms()    # 按键业务逻辑
 ├─ if(msCnt%500==0) Timing_500ms()   # 控制+报警
 └─ if(msCnt%1000==0) Timing_1s()     # 喂食+OLED刷新
```

### 各定时任务详细职责

| 周期 | 函数 | 任务 | 对应需求 |
|------|------|------|---------|
| 1ms | `Timing_1ms()` | 蜂鸣器扫描、LED扫描、按键物理扫描 | — |
| 10ms | `Timing_10ms()` | ADC 轮流采集 3 通道（空气质量/水位/PH） | F-ENV-002~004 |
| 50ms | `Timing_50ms()` | `KEY_Scan()` 按键事件处理 → 页面切换/模式切换/阈值调整 | F-HMI-001~003 |
| 500ms | `Timing_500ms()` | `Auto_Control()` 自动控制 + `Alarm_Process()` 报警判断 | F-CTL-001~003, F-ALR-* |
| 1s | `Timing_1s()` | `Feed_Process()` 喂食倒计时 + `OLED_Refresh()` 刷新当前页面 | F-CTL-004, F-DIS-* |

## 6. 业务逻辑流程

### 6.1 页面导航状态机

> 对应需求规格书 §3 按键功能定义 + §4 OLED 显示页面

```
              KEY1                    KEY1
  ┌──────────────────────┐  ┌──────────────────────┐
  │                      ▼  │                      ▼
┌──────┐  KEY1  ┌──────────┐  KEY2  ┌──────────┐
│ 主页 │ ─────→ │ 自动设置  │ ─────→ │ 手动控制  │
│ (P0) │        │  (P1)    │        │  (P2)    │
└──┬───┘        └────┬─────┘        └────┬─────┘
   │                 │                    │
   │ KEY2            │ KEY1/KEY2         │ KEY2
   └─────────────────┘←──────────────────┘
```

- **KEY1 (PA8)**：设置页/手动页返回主页
- **KEY2 (PB3)**：任何页面循环切换 P0→P1→P2→P0
- **全局变量** `CurrentPage` 维护当前页面（0/1/2）

### 6.2 按键功能矩阵

> 对应需求规格书 §3.1

| 按键 | 主页 (P0) | 自动设置 (P1) | 手动控制 (P2) |
|------|-----------|---------------|---------------|
| KEY1 | 进入设置 | 返回主页 | 返回主页 |
| KEY2 | 切下一页 | 选下一项 | 选下一项 |
| KEY3 | 切手/自动 | 阈值 +1 | 设备开/关 |
| KEY4 | — | 阈值 -1 | — |
| KEY5 | 长按2s 喂食 | — | — |

### 6.3 自动控制逻辑

> 对应需求规格书 §5.3

```
Auto_Control() [每500ms执行，仅自动模式]

  温度控制：
    if(WaterTemp < TempLower) → 开加热(Relay_HEAT=ON)
    if(WaterTemp > TempUpper) → 关加热(Relay_HEAT=OFF)
    else → 维持当前状态（滞环控制）

  水位控制：
    if(WaterLevel > WaterLevel_Max) → 开排水(Relay_DRAIN=ON), 关加水
    if(WaterLevel < WaterLevel_Min) → 开加水(Relay_FILL=ON), 关排水
    else → 两个继电器均关闭（安全区间）

  空气质量控制：
    if(AirQuality > AirQuality_Max) → 开增氧(Relay_OXYGEN=ON)
    else → 关增氧(Relay_OXYGEN=OFF)
```

### 6.4 报警逻辑

> 对应需求规格书 §5.4

```
Alarm_Process() [每500ms执行]

  if(!Alarm_Enable) → 跳过

  检查4类报警源：
    温度越限 → TempLow/High_Alarm = 1
    水位异常 → WaterLevel_Alarm = 1
    空气超标 → AirQuality_Alarm = 1
    PH 越限  → PHLow/High_Alarm = 1

  if(任一报警激活) → BEEP_Blink(1,0,0) + LED_Blink

  报警方式：响0.5s / 停2s 循环
  解除条件：对应参数回到正常范围自动解除
```

### 6.5 喂食控制

> 对应需求规格书 §5.3 F-CTL-004

```
Feed_Process() [每1秒执行]

  ┌─ 手动触发(KEY5长按/手动页) → Feed_Trigger=1
  │
  ├─ if(Feed_Trigger && !Feeding)
  │     → Servo_SetAngle(90), Servo_Timer=0, Feeding=1
  │
  ├─ if(Countdown > 0)
  │     → Countdown--
  │     if(Countdown == 0 && !Feeding)
  │       → Servo_SetAngle(90), Servo_Timer=0, Feeding=1
  │
  └─ if(Servo_Open)
        → Servo_Timer++
        if(Servo_Timer >= 3)
          → Servo_Off(), Feeding=0, 重置Countdown=FeedInterval
```

### 6.6 模式切换

> 对应需求规格书 §5.5

```
自动→手动 (RunMode: 0→1):
  1. Relay_AllOff()          ← 关闭所有继电器
  2. 手动开关标志全部清零
  3. RunMode = 1

手动→自动 (RunMode: 1→0):
  1. Relay_AllOff()          ← 关闭所有继电器
  2. 手动开关标志全部清零
  3. RunMode = 0
  4. 下一个500ms Auto_Control() 自动接管
```

### 6.7 传感器采集

> 对应需求规格书 §5.1

```
Timing_10ms() 中 ADC 轮询采集（3通道轮流）：

  通道0: PA4 (ADC1_IN4) → AirQuality  (原始值)
  通道1: PA1 (ADC1_IN1) → WaterLevel  (ADC×100/4095 → 百分比)
  通道2: PA0 (ADC1_IN0) → PH_Value    (ADC×14.0/4095.0 → PH值)

DS18B20 温度采集：
  由 Timing_10ms 或 Timing_1s 调用 DS18B20_ReadTemp()
  返回 float 摄氏温度值
```

## 7. OLED 页面布局

> 对应需求规格书 §4

OLED 为 128×64 像素，使用 6×12 字体，每行占 2 页，共 4 个视觉行。

### 7.1 主页面 (CurrentPage=0)

```
┌────────────────────────────────────┐
│ 温25.0C    空气320                 │  ← 行0 (页0-1)
│ 水位75%    PH7.2                   │  ← 行2 (页2-3)
│ 模自       喂02:30                 │  ← 行4 (页4-5)
│ 热+  氧-  排-  加-                │  ← 行6 (页6-7)
└────────────────────────────────────┘
```

- 继电器状态：`+` = 开启，`-` = 关闭
- 喂食中显示 `FEED`，无倒计时显示 `--:--`

### 7.2 自动阈值设置页 (CurrentPage=1)

```
┌────────────────────────────────────┐
│ AutoSet                            │
│ 温度Lo: 20.0                       │  ← 选中项反显
│ 温度Hi: 30.0                       │
│ AirMax: 500                        │
│ ... (更多项，KEY2循环选择)           │
└────────────────────────────────────┘
```

### 7.3 手动控制页 (CurrentPage=2)

```
┌────────────────────────────────────┐
│ Manual                             │
│ 加热: 开/关  ← 选中项反显           │
│ 加水: 开/关                         │
│ 排水: 开/关                         │
│ ... (6项，KEY2循环选择，KEY3切换)    │
```
