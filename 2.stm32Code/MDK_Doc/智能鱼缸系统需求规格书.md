> 版本：V1.1 | 日期：2026-05-01 | 状态：修订版
>
> 关联文档：[智能鱼缸系统代码框架与业务流程](./智能鱼缸系统代码框架与业务流程.md)

## 1. 项目概述

| 项目 | 内容 |
|------|------|
| **项目名称** | 基于 STM32 的智能鱼缸监控系统 |
| **目标描述** | 实现鱼缸水质环境的实时监测与自动控制，包括水温、水位、空气质量、PH值等参数的采集、OLED 显示、声光报警、WiFi 远程通信，以及排水/加水/增氧/加热等执行机构的自动/手动控制 |
| **主控平台** | STM32F103C8T6（ARM Cortex-M3, 72MHz, 64KB Flash, 20KB SRAM） |
| **开发环境** | Keil MDK-ARM |

## 3. 按键功能定义

### 3.1 按键功能总览

| 按键 | 引脚 | 主页面 | 自动阈值设置页 | 手动控制页 |
|------|------|--------|---------------|-----------|
| KEY1 | PA8 | 进入自动阈值设置 | 返回主页面 | 返回主页面 |
| KEY2 | PB3 | 切换下一个页面 | 选择下一个参数项 | 选择下一个设备项 |
| KEY3 | PB4 | 切换手/自动模式 | 当前参数阈值 +1 | 当前设备 开/关 切换 |
| KEY4 | PB8 | — | 当前参数阈值 -1 | — |
| KEY5 | PB1 | 长按2秒：立即触发喂食 | — | — |

### 3.2 页面导航逻辑

```
主页面 ──KEY1──→ 自动阈值设置页
  │                │
  │ KEY2           │ KEY1 / KEY2
  ↓                ↓
手动控制页 ←──KEY1──┘
  │
  │ KEY2
  ↓
主页面
```

> **人性化设计**：KEY2 作为"页面循环切换"键，任何页面按 KEY2 都能切换到下一个页面。KEY1 始终作为"返回"键。

## 4. OLED 显示页面

> **字体说明**：全部页面统一使用 6×12 字体（每行最多 21 个字符）。OLED 为 128×64 像素，共 8 页，每行占 1 页，最多显示 8 行。

### 4.1 主页面（上电默认）

```
行1: 温度: 24.0 ℃
行2: 空气质量: 320
行3: 水位: 75%
行4: PH值: 7.2
行5: 模式: 自动
行6: 喂食: 02:30
行7: 加热[关] 增氧[开]
行8: 排水[关] 加水[关]
```

- 行1~4：实时传感器数据
- 行5：当前工作模式（手动/自动）
- 行6：喂食倒计时（MM:SS 格式），无倒计时显示 `--:--`
- 行7~8：当前各继电器实时状态

### 4.2 自动阈值设置页

```
行1: -- 自动阈值设置 --
行2: 温度下限: 20.0 ℃
行3: 温度上限: 30.0 ℃
行4: 空气阈值: 500
行5: PH值下限: 6.5
行6: PH值上限: 8.5
行7: 水位下限: 40%
行8: 喂食间隔: 04:00:00
```

- KEY2 循环选择当前编辑项（高亮/反显标识）
- KEY3 加1，KEY4 减1
- 喂食间隔格式 HH:MM:SS，最短10秒，最长24小时

### 4.3 手动控制页

```
行1: -- 手动控制 --
行2: 加热: 关
行3: 加水: 关
行4: 排水: 关
行5: 增氧: 关
行6: 报警: 开
行7: 喂食: 关
行8: [KEY3] 切换开关
```

- KEY2 循环选择当前设备项
- KEY3 切换 开/关

## 5. 功能需求

### 5.1 环境监测模块

| 功能 ID | 功能名称 | 功能描述 | 输入 | 输出 | 优先级 |
|---------|---------|---------|------|------|--------|
| F-ENV-001 | 水温采集 | DS18B20 采集水温，精度 ±0.5°C，12bit 转换 | PB13 1-Wire | 水温值（°C） | P0-必须 |
| F-ENV-002 | 水位检测 | 水位传感器 ADC 采集，转换为百分比 | PA1 ADC1_IN1 | 水位百分比（0~100%） | P0-必须 |
| F-ENV-003 | 空气质量检测 | MQ-135 检测鱼缸周边空气质量 | PA4 ADC1_IN4 | 空气质量数值 | P1-重要 |
| F-ENV-004 | PH 值检测 | PH 传感器检测水质酸碱度 | PA0 ADC1_IN0 | PH 值（0~14） | P1-重要 |

### 5.2 显示模块

| 功能 ID | 功能名称 | 功能描述 | 优先级 |
|---------|---------|---------|--------|
| F-DIS-001 | 主页面显示 | 8行显示全部传感器数据、模式、设备状态、喂食倒计时 | P0-必须 |
| F-DIS-002 | 自动阈值设置页 | 显示并可编辑温度上下限、空气阈值、PH上下限、水位下限、喂食间隔 | P1-重要 |
| F-DIS-003 | 手动控制页 | 显示各设备开关状态，支持手动切换 | P0-必须 |

### 5.3 控制模块

| 功能 ID | 功能名称 | 功能描述 | 条件 | 输出 | 优先级 |
|---------|---------|---------|------|------|--------|
| F-CTL-001 | 温度控制 | 低于下限开加热，高于上限关加热，区间内维持当前状态 | 自动模式 | PB12 继电器 | P0-必须 |
| F-CTL-002 | 水位控制 | 高于上限开排水，低于下限开加水，区间内均关闭 | 自动模式 | PB15/PB14 继电器 | P0-必须 |
| F-CTL-003 | 增氧控制 | 空气质量数值 > 阈值时开增氧，≤ 阈值时关闭 | 自动模式 | PA15 继电器 | P1-重要 |
| F-CTL-004 | 喂食控制 | 倒计时归零时舵机开启3秒后关闭；KEY5 长按可手动触发 | 全模式 | PA6 舵机 | P1-重要 |
| F-CTL-005 | 手动控制 | 用户通过按键强制开关各继电器 | 手动模式 | 各继电器 | P0-必须 |

### 5.4 报警模块

| 功能 ID | 报警源 | 触发条件 | 解除条件 | 方式 |
|---------|--------|---------|---------|------|
| F-ALR-001 | 温度越限 | 水温 < 下限 或 > 上限 | 回到正常范围 | 蜂鸣器短鸣 + LED |
| F-ALR-002 | 水位异常 | 水位 < 下限 或 > 上限 | 回到正常范围 | 蜂鸣器短鸣 + LED |
| F-ALR-003 | 空气超标 | 空气质量数值 > 阈值 | ≤ 阈值 | 蜂鸣器短鸣 + LED |
| F-ALR-004 | PH越限 | PH < 下限 或 > 上限 | 回到正常范围 | 蜂鸣器短鸣 + LED |

> 报警方式：响 0.5 秒 / 停 2 秒循环，手动模式下可通过"报警: 关"临时关闭。

### 5.5 模式切换规则

| 切换 | 动作 |
|------|------|
| 自动 → 手动 | 立即关闭所有继电器设备，用户按需手动开启 |
| 手动 → 自动 | 关闭所有设备 → 根据当前阈值和传感器数据重新判断各设备状态 |

### 5.6 通信模块（手机APP）

| 功能 ID | 功能 | 方向 | 说明 |
|---------|------|------|------|
| F-COM-001 | 实时数据上报 | MCU → APP | 温度、空气质量、水位、PH值、模式、喂食倒计时 |
| F-COM-002 | 模式切换 | APP → MCU | 远程切换手动/自动模式 |
| F-COM-003 | 阈值设置 | APP → MCU | 仅自动模式下可设置各参数阈值 |
| F-COM-004 | 设备控制 | APP → MCU | 仅手动模式下可开关各设备 |
| F-COM-005 | 喂食触发 | APP → MCU | 远程触发一次喂食 |

> ESP-01S 通过 USART2（PA2=RX, PA3=TX），波特率 115200。

## 6. 接口需求

| 外设 | 通信协议 | 引脚 | 通信参数 |
|------|---------|------|---------|
| OLED（SSD1306） | I²C（软件模拟） | SCL=PA12, SDA=PA11 | 地址 0x78 |
| DS18B20 | 1-Wire | DATA=PB13 | 精度 12bit，转换时间 ~750ms，需 4.7kΩ 上拉 |
| ESP-01S | UART | TX→MCU=PA2, RX←MCU=PA3 | USART2，115200 8N1 |
| MQ-135 | ADC | AO=PA4 | ADC1_IN4，12bit，0~3.3V |
| PH 传感器 | ADC | AO=PA0 | ADC1_IN0，12bit，0~3.3V |
| 水位传感器 | ADC | AO=PA1 | ADC1_IN1，12bit，0~3.3V |
| 舵机 | PWM | PA6 | TIM3_CH1，50Hz（20ms周期），脉宽 0.5ms~2.5ms |
| LED+蜂鸣器 | GPIO | PB9 | 推挽输出，高电平有效 |
| 按键 ×5 | GPIO | PA8/PB3/PB4/PB8/PB1 | 浮空输入，软件消抖 |
| 继电器 ×4 | GPIO | PB15/PA15/PB14/PB12 | 推挽输出，高电平有效 |

## 7. 性能需求

| 指标 | 要求 |
|------|------|
| 水温采样周期 | ≤ 2s（DS18B20 12bit 转换约 750ms） |
| 水位/PH/空气质量采样周期 | ≤ 500ms（ADC 软件采集） |
| OLED 刷新周期 | 1s（与定时器 1s 任务同步） |
| 按键响应时间 | ≤ 50ms（软件消抖） |
| 报警响应时间 | 超限后 ≤ 1s 触发声光报警 |
| 喂食舵机动作时间 | 固定 3 秒 |
| WiFi 数据上报周期 | 1s（与 OLED 刷新同步） |
| 继电器响应时间 | ≤ 100ms |

## 8. 定时器调度方案

| 周期 | 任务 |
|------|------|
| 1ms | 蜂鸣器扫描（`BEEP_DrvScan`）、LED扫描（`LED_DrvScan`）、按键扫描（`KEY_DrvScan`） |
| 10ms | 传感器数据采集（ADC轮询） |
| 50ms | 按键事件处理（`KEY_Scan`） |
| 500ms | 报警逻辑判断、设备控制执行 |
| 1s | 喂食倒计时递减、OLED 刷新、WiFi 数据上报 |

## 9. 系统启动流程

```
1. 上电 / 复位
2. NVIC 分组配置（Group_4）
3. 延时初始化（72MHz）
4. 定时器初始化（TIM2 + TIM3）
5. GPIO 复用配置（关闭 PB3/PB4 的 JTAG 功能）
6. 各外设初始化：LED → 蜂鸣器 → 按键 → OLED → ADC → USART → DS18B20 → 舵机
7. OLED 显示启动画面 "智能鱼缸系统" 持续 2 秒
8. 加载默认阈值参数
9. 所有继电器关闭，舵机关闭
10. 进入主页面，定时器调度启动
```
