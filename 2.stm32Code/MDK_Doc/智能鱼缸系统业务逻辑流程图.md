## 1. 系统启动流程 (main.c)

```
┌─────────────────────────┐
│        上电/复位          │
└────────────┬────────────┘
             ▼
┌─────────────────────────┐
│  NVIC_PriorityGroup(4)  │  中断优先级分组
│  delay_init(72MHz)      │  延时初始化
│  GENERAL_TIM_Init()     │  TIM2+TIM3 定时器
└────────────┬────────────┘
             ▼
┌─────────────────────────┐
│  RCC_AFIO 时钟使能       │
│  关闭 JTAG (PB3/PB4)    │  GPIO复用配置
└────────────┬────────────┘
             ▼
┌─────────────────────────┐
│  LED_Init()             │  PB9 输出
│  Beep_Init()            │  PB9 输出
│  KEY_GPIO_Config()      │  5个按键 GPIO
│  OLED_Init()            │  PA12/PA11 I2C
│  ADCx_Init()            │  ADC1 多通道
│  DS18B20_Init()         │  PB13 1-Wire
│  Relay_Init()           │  4路继电器全关
│  Servo_Init()           │  PA6 TIM3 PWM
│  FireUSART_1_Config()   │  PA2/PA3 USART2
└────────────┬────────────┘
             ▼
┌─────────────────────────┐
│  OLED_ShowStart()       │  显示"智能鱼缸系统"
│  delay_ms(2000)         │  停留2秒
└────────────┬────────────┘
             ▼
┌─────────────────────────┐
│  SysFlag_Init()         │  加载默认阈值
│  RunMode=0 (自动)       │
│  Alarm_Enable=1         │
│  Countdown=FeedInterval │
│  Servo_Off()            │
└────────────┬────────────┘
             ▼
┌─────────────────────────┐
│  OLED_ShowMainPage()    │  进入主页面
└────────────┬────────────┘
             ▼
┌─────────────────────────┐
│  while(1)               │
│  {                      │
│      IWDG_Feed();       │  喂看门狗
│  }                      │
└─────────────────────────┘
  (所有业务逻辑在 TIM2 中断中执行)
```

## 2. 定时器调度流程 (stm32f10x_it.c → TimingSet.c)

```
TIM2_IRQHandler (每 1ms 触发)
│
├── TimeCnt_ms++              # 全局毫秒计数器
├── msCnt++                   # 本地计数器 (0~59999 循环)
│
├── Timing_1ms()              # ──── 每次必执行 ────
│   ├── BEEP_DrvScan()        # 蜂鸣器状态机 (1ms步进)
│   ├── LED_DrvScan()         # LED 闪烁状态机 (100ms步进)
│   └── KEY_DrvScan()         # 按键物理扫描 (消抖+长按检测)
│
├── if(msCnt%2==0)   Timing_2ms()    # 空函数
├── if(msCnt%5==0)   Timing_5ms()    # 空函数
│
├── if(msCnt%10==0)  Timing_10ms()   # ──── 传感器采集 ────
│   ├── Check_SysWorkStatus()         # 空函数 (预留)
│   └── ADC 轮询 (3通道轮流):
│       ├── idx=0: PA4 → AirQuality   (原始值)
│       ├── idx=1: PA1 → WaterLevel   (×100/4095 → %)
│       └── idx=2: PA0 → PH_Value     (×14.0/4095 → PH)
│
├── if(msCnt%50==0)  Timing_50ms()   # ──── 按键业务 ────
│   └── KEY_Scan()                    # 按键事件处理 → 页面/模式/阈值
│
├── if(msCnt%500==0) Timing_500ms()  # ──── 控制+报警 ────
│   ├── Auto_Control()                # 自动模式设备控制
│   └── Alarm_Process()               # 4类报警源判断
│
└── if(msCnt%1000==0) Timing_1s()    # ──── 喂食+显示+温度 ────
    ├── DS18B20 分步读取 (非阻塞)
    │   ├── step=0: DS18B20_StartConvert()  # 发送0x44
    │   └── step=1: DS18B20_ReadTemp()      # 读取结果+范围检查
    ├── Feed_Process()               # 喂食倒计时+舵机控制
    └── OLED_Refresh()               # 刷新当前页面
```

## 3. 自动控制流程 (Auto_Control - 每500ms)

```
Auto_Control()
│
├── if(RunMode != 0) return   # 非自动模式, 跳过
│
├── [温度控制]
│   ├── WaterTemp < TempLower ?
│   │   └── YES → Relay_HEAT = ON (加热)
│   ├── WaterTemp > TempUpper ?
│   │   └── YES → Relay_HEAT = OFF
│   └── 在上下限之间 → 维持当前状态 (滞环)
│
├── [水位控制]
│   ├── WaterLevel > WaterLevel_Max ?
│   │   ├── YES → Relay_FILL = OFF
│   │   └── YES → Relay_DRAIN = ON (排水)
│   ├── WaterLevel < WaterLevel_Min ?
│   │   ├── YES → Relay_DRAIN = OFF
│   │   └── YES → Relay_FILL = ON (加水)
│   └── 在安全区间 → Relay_DRAIN = OFF, Relay_FILL = OFF
│
└── [空气质量控制]
    ├── AirQuality > AirQuality_Max ?
    │   └── YES → Relay_OXYGEN = ON (增氧)
    └── NO → Relay_OXYGEN = OFF
```

**温度滞环示意**：
```
        TempUpper ──────── Relay_HEAT = OFF
             │
             │   安全区间 (维持当前状态)
             │
        TempLower ──────── Relay_HEAT = ON
```

**水位区间示意**：
```
        100% ─────
             │
        Max ──────── 开始排水 (Relay_DRAIN=ON)
             │
             │   安全区间 (两继电器均OFF)
             │
        Min ──────── 开始加水 (Relay_FILL=ON)
             │
         0% ─────
```

## 4. 报警逻辑流程 (Alarm_Process - 每500ms)

```
Alarm_Process()
│
├── if(!Alarm_Enable) return    # 报警关闭, 跳过
│
├── alarm_active = 0
│
├── [温度检查]
│   ├── WaterTemp < TempLower OR WaterTemp > TempUpper ?
│   │   ├── YES → TempLow/High_Alarm = 1, alarm_active = 1
│   │   └── NO  → TempLow/High_Alarm = 0
│
├── [水位检查]
│   ├── WaterLevel < Min OR WaterLevel > Max ?
│   │   ├── YES → WaterLevel_Alarm = 1, alarm_active = 1
│   │   └── NO  → WaterLevel_Alarm = 0
│
├── [空气质量检查]
│   ├── AirQuality > AirQuality_Max ?
│   │   ├── YES → AirQuality_Alarm = 1, alarm_active = 1
│   │   └── NO  → AirQuality_Alarm = 0
│
├── [PH值检查]
│   ├── PH < PH_Lower OR PH > PH_Upper ?
│   │   ├── YES → PHLow/High_Alarm = 1, alarm_active = 1
│   │   └── NO  → PHLow/High_Alarm = 0
│
└── if(alarm_active)
    ├── BEEP_SetCycleDuty(2500, 500)    # 周期2.5s, 响0.5s
    ├── BEEP_Blink(1, 0, 100)           # 无限重复
    ├── LED_BlinkSetCycleDuty(LED1, 25, 5)  # 周期2.5s, 亮0.5s
    └── LED_Blink(LED1, 1, 0, 100)      # 无限重复

报警解除: 对应参数回到正常范围 → 标志自动清零 → 蜂鸣器/LED 自动停止
```

## 5. 喂食控制流程 (Feed_Process - 每1s)

```
Feed_Process()
│
├── [手动触发检查]
│   ├── if(Feed_Trigger)
│   │   ├── Feed_Trigger = 0 (清标志)
│   │   ├── if(!Feeding)
│   │   │   ├── Feeding = 1
│   │   │   ├── Servo_Open = 1
│   │   │   ├── Servo_Timer = 0
│   │   │   └── Servo_SetAngle(90)    ← 舵机打开
│
├── [倒计时递减]
│   ├── if(Countdown > 0)
│   │   ├── Countdown--
│   │   └── if(Countdown == 0 && !Feeding)
│   │       ├── Feeding = 1, Servo_Open = 1
│   │       ├── Servo_Timer = 0
│   │       └── Servo_SetAngle(90)    ← 倒计时归零触发
│
└── [舵机超时关闭]
    ├── if(Servo_Open)
    │   ├── Servo_Timer++
    │   └── if(Servo_Timer >= 3)       ← 3秒后
    │       ├── Servo_Off()            ← 舵机关闭
    │       ├── Servo_Open = 0
    │       ├── Feeding = 0
    │       └── Countdown = FeedInterval  ← 重置倒计时

喂食状态机:
  ┌──────────┐  触发   ┌──────────┐  3秒后  ┌──────────┐
  │  待机     │ ─────→ │ 舵机打开  │ ─────→ │ 舵机关闭  │
  │ Countdown │        │ Servo_Open│        │ 重置倒计时│
  └──────────┘        └──────────┘        └──────────┘
```

## 6. 按键业务流程 (KEY_Scan - 每50ms)

### 6.1 物理按键扫描 (KEY_DrvScan - 每1ms)

```
KEY_DrvScan() [每个按键独立状态机]
│
├── 读取当前按键电平 (pressCurr)
│
├── 状态0: 稳定态
│   ├── 电平变化 → 进入滤波态 (step=1, filterCnt=0)
│   ├── 按住中 → holdingCnt++
│   │   ├── holdingCnt == 200 (2秒) → KEY_Write(KEY+Long2S)
│   │   └── holdingCnt == 400 (4秒) → KEY_Write(KEY+Long4S)
│
└── 状态1: 滤波态 (消抖)
    ├── 连续5次一致 → 状态确认
    │   ├── 确实按下 → KEY_Write(KEY+Press), holdingCnt=0
    │   └── 确实松开 → KEY_Write(KEY+Release)
    └── 不一致 → 回到稳定态
```

### 6.2 页面导航状态机

```
        ┌─────────────────────────────────────┐
        │              主页 (P0)              │
        │  温度 空气  水位 PH  模式 喂食 状态 │
        └──┬──────────────────────────────┬───┘
    KEY1 ↓                          KEY2 ↓
  ┌──────────────────┐     ┌──────────────────┐
  │  自动设置 (P1)   │     │  手动控制 (P2)   │
  │  温Lo/Hi 空气    │     │  加热/加水/排水   │
  │  PH Lo/Hi 水位   │     │  增氧/报警/喂食   │
  │  喂食间隔        │     │                  │
  └──┬───────────┬───┘     └──┬───────────┬───┘
 KEY1↓      KEY2↓          KEY1↓      KEY2↓
     └──→ 主页 ←──────────────┘          │
                                         ↓
                                    ┌────────┐
                                    │  主页   │
                                    └────────┘
```

### 6.3 按键功能矩阵

| 按键 | 事件 | 主页 (P0) | 自动设置 (P1) | 手动控制 (P2) |
|------|------|-----------|---------------|---------------|
| KEY1 (PA8) | 短按 | → 进入设置页 | → 返回主页 | → 返回主页 |
| KEY2 (PB3) | 短按 | P0→P1→P2→P0 | 选中项下移 (循环) | 选中项下移 (循环) |
| KEY3 (PB4) | 短按 | 切换手/自动 | 当前项 +1 | 当前设备 开/关 |
| KEY4 (PB8) | 短按 | — | 当前项 -1 | — |
| KEY5 (PB1) | 长按2s | 触发喂食 | — | — |

### 6.4 模式切换流程

```
KEY3 在主页按下:
│
├── 当前 RunMode == 0 (自动)?
│   └── YES
│       ├── Relay_AllOff()                    # 关闭所有继电器
│       ├── Relay_*_Manual 全部清零
│       └── RunMode = 1                       # 切换到手动
│
└── 当前 RunMode == 1 (手动)?
    └── YES
        ├── Relay_AllOff()                    # 关闭所有继电器
        ├── Relay_*_Manual 全部清零
        └── RunMode = 0                       # 切换到自动
            (下一个 500ms Auto_Control() 自动接管)
```

### 6.5 自动设置页操作流程

```
7个设置项: 索引 0~6
┌──────────┬──────────────────┬───────┬───────┐
│  索引    │     参数         │ KEY3加 │ KEY4减 │
├──────────┼──────────────────┼───────┼───────┤
│  0       │ 温度下限 (°C)    │ +1.0  │ -1.0  │
│  1       │ 温度上限 (°C)    │ +1.0  │ -1.0  │
│  2       │ 空气质量阈值     │ +10   │ -10   │
│  3       │ PH 下限          │ +0.5  │ -0.5  │
│  4       │ PH 上限          │ +0.5  │ -0.5  │
│  5       │ 水位下限 (%)     │ +5    │ -5    │
│  6       │ 喂食间隔 (秒)    │ +60   │ -60   │
└──────────┴──────────────────┴───────┴───────┘

KEY2 短按 → AutoSet_Index = (Index+1) % 7 (循环选中)
选中项中文字符反显 (inv=1)
```

### 6.6 手动控制页操作流程

```
6个控制项: 索引 0~5
┌──────────┬──────────────────┬──────────────┐
│  索引    │     设备         │   KEY3操作    │
├──────────┼──────────────────┼──────────────┤
│  0       │ 加热 (PB12)      │ 开/关切换    │
│  1       │ 加水 (PB14)      │ 开/关切换    │
│  2       │ 排水 (PB15)      │ 开/关切换    │
│  3       │ 增氧 (PA15)      │ 开/关切换    │
│  4       │ 报警             │ 使能/禁用    │
│  5       │ 喂食             │ 触发一次     │
└──────────┴──────────────────┴──────────────┘

KEY2 短按 → ManualSet_Index = (Index+1) % 6 (循环选中)
选中项中文字符反显 (inv=1)
```

## 7. 传感器采集流程 (Timing_10ms - 每10ms)

```
Timing_10ms()
│
├── adc_channel_idx++ (0→1→2→0 循环)
│
├── [通道 0: 空气质量]
│   ├── ADC_RegularChannelConfig(ADC1, Channel_4)
│   ├── ADC_SoftwareStartConv
│   ├── 等待 EOC 标志
│   └── AirQuality = ADC_GetValue()        # PA4, 原始值 0~4095
│
├── [通道 1: 水位]
│   ├── ADC_RegularChannelConfig(ADC1, Channel_1)
│   ├── ADC_SoftwareStartConv
│   ├── 等待 EOC 标志
│   └── WaterLevel = ADC×100/4095          # PA1, 转百分比 0~100%
│
└── [通道 2: PH值]
    ├── ADC_RegularChannelConfig(ADC1, Channel_0)
    ├── ADC_SoftwareStartConv
    ├── 等待 EOC 标志
    └── PH_Value = ADC×14.0/4095.0         # PA0, 转PH值 0~14

DS18B20 温度采集 (Timing_1s 非阻塞):
┌──────────┐  奇数秒  ┌──────────┐  偶数秒  ┌──────────┐
│ 空闲     │ ──────→ │ 转换中   │ ──────→ │ 读取完成  │
│ step=0   │  0x44   │ step=1   │  读数据  │ 更新温度  │
└──────────┘         └──────────┘         └──────────┘
```

## 8. OLED 页面刷新流程 (OLED_Refresh - 每1s)

```
OLED_Refresh()
│
├── switch(CurrentPage)
│   ├── case 0: OLED_ShowMainPage()
│   │   ├── 温度 + 空气质量
│   │   ├── 水位 + PH值
│   │   ├── 模式(自/手) + 喂食倒计时
│   │   └── 继电器状态: 热+氧-排-加-
│   │
│   ├── case 1: OLED_ShowAutoSetPage()
│   │   ├── 屏1 (Index 0-3): 温Lo/温Hi/空气/PH Lo
│   │   └── 屏2 (Index 4-6): PH Hi/水位/喂食间隔
│   │
│   └── case 2: OLED_ShowManualPage()
│       ├── 屏1 (Index 0-3): 加热/加水/排水/增氧
│       └── 屏2 (Index 4-5): 报警/喂食
```
