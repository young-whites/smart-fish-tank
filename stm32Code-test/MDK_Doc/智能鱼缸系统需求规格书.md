# 智能鱼缸系统需求规格书（裸机版）

> 版本：v2.0 | 更新日期：2026-05-04
> 项目：基于 STM32 的智能鱼缸系统
> 目标 MCU：STM32F103C8T6
> 操作系统：裸机（Bare-Metal），TIM2 中断调度
> 开发环境：Keil MDK-ARM v5

---

## 1 项目概述

### 1.1 项目名称
基于 STM32 的智能鱼缸监控系统

### 1.2 项目目标
设计并实现一款低成本、低功耗、易扩展的智能鱼缸监控系统，通过传感器实时采集水质参数，自动控制加热、加水、排水、增氧等执行机构，并通过 OLED 本地显示与 WiFi 远程上报实现双通道人机交互。

### 1.3 目标用户
- 观赏鱼爱好者（家庭用户）
- 水产养殖初学者
- 嵌入式课程设计 / 毕业设计参考

### 4.2 TIM2 中断调度

| 参数 | 值 | 说明 |
|------|-----|------|
| 定时器 | TIM2 | 通用定时器 |
| 中断周期 | 1ms | 1kHz 中断频率 |
| 预分频 | 71 | 72MHz / 72 = 1MHz |
| 自动重装 | 999 | 1MHz / 1000 = 1kHz |

调度时序：

| 函数 | 周期 | 职责 |
|------|------|------|
| Timing_1ms() | 1ms | BEEP 蜂鸣器状态机 + KEY_DrvScan() 按键底层扫描 |
| Timing_2ms() | 2ms | LED 扫描 |
| Timing_5ms() | 5ms | ADC 轮询采集 (PA0/PA1/PA4) |
| Timing_10ms() | 10ms | 传感器数据中间值处理 |
| Timing_50ms() | 50ms | KEY_Scan() 按键事件处理 |
| Timing_500ms() | 500ms | Sensor_Read() + Auto_Control() + Alarm_Check() |
| Timing_1s() | 1s | Display_Refresh() + Feed_Control() + WiFi_Report() |

## 5 全局数据结构

### 5.1 Flag_StructType（系统标志）

```c
typedef struct {
    uint8_t currentPage;       // 主页面 0=数据, 1=阈值, 2=手动
    uint8_t subPage;           // 子页面索引
    uint8_t thresholdField;    // 阈值: 0=下限, 1=上限
    uint8_t thresholdIndex;    // 当前选中参数索引
    uint8_t alarmEnable;       // 报警使能
    uint8_t feeding;           // 喂食中标志
    uint8_t relayHeat;         // 加热继电器
    uint8_t relayFill;         // 加水继电器
    uint8_t relayDrain;        // 排水继电器
    uint8_t relayOxygen;       // 增氧继电器
} Flag_StructType;
```

### 5.2 Record_StructType（传感器数据与阈值）

```c
typedef struct {
    float waterTemp;           // 水温 °C
    float phValue;             // PH 值
    uint8_t waterLevel;        // 水位 0~100%
    uint16_t airQuality;       // 空气质量 ADC 原始值
    uint8_t runMode;           // 0=自动, 1=手动
    uint16_t feedCountdown;    // 喂食倒计时 (秒)
    float tempLower;           // 温度下限
    float tempUpper;           // 温度上限
    uint16_t airQualityMax;    // 空气质量上限
    float phLower;             // PH 下限
    float phUpper;             // PH 上限
    uint8_t waterLevelMin;     // 水位下限 %
    uint8_t waterLevelMax;     // 水位上限 %
} Record_StructType;
```

## 6 功能需求详细

### 6.1 温度采集与控制

| 项目 | 说明 |
|------|------|
| 负责函数 | Timing_500ms() → Sensor_Read() + Auto_Control() |
| 传感器 | DS18B20, PB1 |
| 采集周期 | 500ms |
| 精度 | ±0.5°C |
| 显示 | OLED 主页面1 子1-1 显示水温 |
| 控制逻辑 | waterTemp < tempLower → relayHeat=ON |
| | waterTemp > tempUpper → relayHeat=OFF |
| | 滞环控制，防止频繁切换 |
| 异常处理 | 传感器断线 → 保持上一次有效值 |

### 6.2 水位监测与控制

| 项目 | 说明 |
|------|------|
| 负责函数 | Timing_500ms() |
| 传感器 | 模拟水位传感器, PA1 (ADC1_IN1) |
| 数值范围 | 0~100% |
| 显示 | OLED 主页面1 子1-2 |
| 控制逻辑 | waterLevel > waterLevelMax → relayDrain=ON, relayFill=OFF |
| | waterLevel < waterLevelMin → relayFill=ON, relayDrain=OFF |
| | 安全区间 → 两继电器均 OFF |

### 6.3 空气质量监测与控制

| 项目 | 说明 |
|------|------|
| 负责函数 | Timing_500ms() |
| 传感器 | MQ-135, PA4 (ADC1_IN4) |
| 数值范围 | 0~4095 ADC 原始值 |
| 控制逻辑 | airQuality > airQualityMax → relayOxygen=ON |
| | else → relayOxygen=OFF |

### 6.4 PH 值监测

| 项目 | 说明 |
|------|------|
| 负责函数 | Timing_500ms() |
| 传感器 | PH 传感器, PA0 (ADC1_IN0) |
| 数值范围 | 0.0~14.0 |
| 显示 | OLED 主页面1 子1-1 |
| 报警 | PH 超出 phLower~phUpper 范围触发报警 |

### 6.5 OLED 显示（详见 OLED显示规划.md）

| 项目 | 说明 |
|------|------|
| 负责函数 | Timing_1s() → Display_Refresh() |
| 屏幕 | SSD1306 128×64 I2C |
| 接口 | PA11 (SDA), PA12 (SCL) |
| 架构 | 3 主页面 × 子页面 |
| | 主页面1：数据显示（3个子页面） |
| | 主页面2：阈值设置（4个子页面） |
| | 主页面3：手动控制（4个子页面） |
| 页码 | 右上角 "1/1" 格式 |

### 6.6 按键处理

| 项目 | 说明 |
|------|------|
| 负责函数 | Timing_1ms() → KEY_DrvScan() 底层扫描 + Timing_50ms() → KEY_Scan() 事件处理 |
| 按键 | KEY1=PA6, KEY2=PA7, KEY3=PB0, KEY4=PA3, KEY5=PA4 |
| 模式 | 上拉输入，高电平触发 |
| 消抖 | 连续 5 次确认 (5ms) |

**功能定义**：

| 按键 | 主页面1（数据） | 主页面2（阈值） | 主页面3（手动） |
|------|----------------|----------------|----------------|
| KEY1 | → 主页面2 | → 主页面3 | → 主页面1 |
| KEY2 | 子页面切换 | 子页面切换 | 手动模式切换继电器 |
| KEY3 | 无功能 | 选中字段+1 | 切换自动/手动模式 |
| KEY4 | 无功能 | 选中字段-1 | 手动模式切换ON/OFF |
| KEY5 | 无功能 | 切换上限/下限 | 无功能 |

### 6.7 喂食控制

| 项目 | 说明 |
|------|------|
| 负责函数 | Timing_1s() → Feed_Control() |
| 执行器 | SG90 舵机, TIM3_CH1 (PA6), 50Hz |
| 自动喂食 | feedCountdown 归零触发 |
| 手动喂食 | KEY5 触发 |
| 动作 | 舵机打开 3 秒后关闭，重置倒计时 |

### 6.8 WiFi 通信

| 项目 | 说明 |
|------|------|
| 负责函数 | USART2 中断 + Timing_1s() |
| 模组 | ESP-01S (ESP8266) |
| 接口 | USART2, PA2(TX)/PA3(RX), 115200bps |
| 协议 | 自定义帧格式，详见《WiFi 通信协议规范》 |
| 上报 | 每 1 秒上报传感器数据 + 设备状态 |

### 6.9 声光报警

| 项目 | 说明 |
|------|------|
| 负责函数 | Timing_500ms() → Alarm_Check() |
| 设备 | 蜂鸣器+LED, PB3 |
| 报警源 | 温度/水位/空气/PH 越限 |
| 报警模式 | 响 0.5s → 停 2s → 循环 |
| 控制 | alarmEnable=0 时完全关闭报警 |

## 7 非功能需求

### 7.1 可靠性
- 传感器异常检测：连续 3 次读取失败标记传感器故障
- 阈值互锁：温度/水位/PH 上下限互锁保护

### 7.2 可维护性
- 模块化设计，每个外设独立 .c/.h
- 全局数据结构集中管理（MyTypedef.h/c）

### 7.3 可扩展性
- Timing 调度框架可轻松添加新周期任务
- OLED 子页面架构支持扩展
