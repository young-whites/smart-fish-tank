## 2. TIM2 中断调度时序

### 2.1 调度时序图

```
TIM2 1ms 中断 → 维护全局计数器 g_tick_ms

g_tick_ms % 1   == 0 → Timing_1ms()    # BEEP 状态机
g_tick_ms % 2   == 0 → Timing_2ms()    # LED 扫描
g_tick_ms % 5   == 0 → Timing_5ms()    # ADC 轮询
g_tick_ms % 10  == 0 → Timing_10ms()   # 传感器中间处理
g_tick_ms % 50  == 0 → Timing_50ms()   # Key_Scan()
g_tick_ms % 500 == 0 → Timing_500ms()  # Sensor_Read() + Auto_Control() + Alarm_Check()
g_tick_ms % 1000== 0 → Timing_1s()     # Display_Refresh() + Feed_Control() + WiFi_Report()
```

### 2.2 各 Timing 函数功能

| 函数 | 周期 | 对应功能 |
|------|------|---------|
| Timing_1ms() | 1ms | BEEP_DrvScan() 蜂鸣器状态机 |
| Timing_2ms() | 2ms | LED_DrvScan() LED 扫描 |
| Timing_5ms() | 5ms | ADC 轮询采集 (PA0/PA1/PA4 三通道轮流) |
| Timing_10ms() | 10ms | 传感器数据中间值处理与滤波 |
| Timing_50ms() | 50ms | Key_Scan() 按键消抖扫描 |
| Timing_500ms() | 500ms | Sensor_Read() + Auto_Control() + Alarm_Check() |
| Timing_1s() | 1s | Display_Refresh() + Feed_Control() + WiFi_Report() |

## 4. 自动控制流程 (Auto_Control() - 每500ms)

```
Auto_Control() 调用入口
│
├── 读取传感器数据 (全局变量直接访问)
│   ├── temp = fish_tank_data.water_temp
│   ├── level = fish_tank_data.water_level
│   └── air = fish_tank_data.air_quality
│
├── if(RunMode != 0) return  # 非自动模式直接返回
│
├── [温度控制]
│   ├── temp < TempLower ?
│   │   └── YES → relay_heat_on() (加热)
│   ├── temp > TempUpper ?
│   │   └── YES → relay_heat_off()
│   └── 在上下限之间 → 维持当前状态 (滞环)
│
├── [水位控制]
│   ├── level > WaterLevel_Max ?
│   │   ├── YES → relay_fill_off()
│   │   └── YES → relay_drain_on() (排水)
│   ├── level < WaterLevel_Min ?
│   │   ├── YES → relay_drain_off()
│   │   └── YES → relay_fill_on() (加水)
│   └── 在安全区间 → relay_drain_off(), relay_fill_off()
│
├── [空气质量控制]
│   ├── air > AirQuality_Max ?
│   │   └── YES → relay_oxygen_on() (增氧)
│   └── NO → relay_oxygen_off()
│
└── [报警事件检测]
    └── if(任一报警条件激活)
        └── g_alarm_event = ALARM_EVENT_ACTIVE  # 设置全局报警标志
```

**温度滞环示意**：
```
        TempUpper ──────── Relay_HEAT = OFF
             │
             │   安全区间 (维持当前状态)
             │
        TempLower ──────── Relay_HEAT = ON
```

**水位区间示意**：
```
        100% ─────
             │
        Max ──────── 开始排水 (Relay_DRAIN=ON)
             │
             │   安全区间 (两继电器均OFF)
             │
        Min ──────── 开始加水 (Relay_FILL=ON)
             │
         0% ─────
```

## 5. 报警逻辑流程 (Alarm_Check() - 每500ms)

```
Alarm_Check() 调用入口
│
├── if(!Alarm_Enable) return    # 报警关闭, 直接返回
│
├── if(g_alarm_event == ALARM_EVENT_ACTIVE)
│   ├── g_alarm_event = 0       # 清标志
│   ├── beep_on(); led_on()
│   ├── g_alarm_state = 1       # 进入报警响状态
│   └── g_alarm_timer = 0       # 重置报警计时器
│
├── if(g_alarm_state)
│   ├── g_alarm_timer++
│   ├── if(g_alarm_timer >= 1 && g_alarm_timer < 6)
│   │   └── beep_on()           # 响 0.5s (500ms×1)
│   └── if(g_alarm_timer >= 6 && g_alarm_timer < 10)
│       ├── beep_off(); led_off()
│       └── if(g_alarm_timer >= 10)
│           └── g_alarm_timer = 0  # 重新循环
│
报警解除: Auto_Control() 不再设置 g_alarm_event → 蜂鸣器/LED 静默
```

## 6. 喂食控制流程 (Feed_Control() - 每1s)

```
Feed_Control() 调用入口
│
├── [手动触发检查]
│   ├── if(Feed_Trigger)
│   │   ├── Feed_Trigger = 0 (清标志)
│   │   ├── if(!Feeding)
│   │   │   ├── Feeding = 1
│   │   │   ├── Servo_Open = 1
│   │   │   ├── Servo_Timer = 0
│   │   │   └── servo_set_angle(90)    ← 舵机打开
│
├── [倒计时递减]
│   ├── if(Countdown > 0)
│   │   ├── Countdown--
│   │   └── if(Countdown == 0 && !Feeding)
│   │       ├── Feeding = 1, Servo_Open = 1
│   │       ├── Servo_Timer = 0
│   │       └── servo_set_angle(90)    ← 倒计时归零触发
│
├── [舵机超时关闭]
│   ├── if(Servo_Open)
│   │   ├── Servo_Timer++
│   │   └── if(Servo_Timer >= 3)       ← 3秒后
│   │       ├── servo_off()            ← 舵机关闭
│   │       ├── Servo_Open = 0
│   │       ├── Feeding = 0
│   │       └── Countdown = FeedInterval  ← 重置倒计时
│
└── 函数返回
```

**喂食状态机**：
```
  ┌──────────┐  触发   ┌──────────┐  3秒后  ┌──────────┐
  │  待机     │ ─────→ │ 舵机打开  │ ─────→ │ 舵机关闭  │
  │ Countdown │        │ Servo_Open│        │ 重置倒计时│
  └──────────┘        └──────────┘        └──────────┘
```

## 7. 按键业务流程 (Key_Scan() + Key_Event_Process())

### 7.1 按键扫描机制（TIM2 50ms 中断中调用）

```
Key_Scan() 调用入口 (每50ms)
│
├── 读取 GPIO 电平
│   ├── KEY1=PA8, KEY2=PB3, KEY3=PB4, KEY4=PB8, KEY5=PA4
│   └── 高电平有效，上拉输入
│
├── 消抖处理 (连续3次一致确认)
│
├── 短按检测
│
└── 写入 g_key_event 全局事件变量

主循环中检查 g_key_event:
│
├── Key_Event_Process()
│   ├── 页面导航 (KEY1/KEY2)
│   ├── 模式切换 (KEY3 主页3)
│   ├── 阈值调整 (KEY3/KEY4 阈值页)
│   ├── 上下限切换 (KEY5 阈值页)
│   └── 继电器手动切换 (KEY2/KEY4 主页3)
│
└── 清除 g_key_event
```

### 7.2 OLED 显示架构（3主页面×子页面）

```
主页面1（数据显示）
  ├── 子1-1：水温 + PH + 状态栏（WiFi/模式/喂食）
  ├── 子1-2：水位 + 空气 + 加热/加水状态
  └── 子1-3：排水/增氧 + ALM/模式

主页面2（阈值设置）
  ├── 子2-1：温度（上下限各一行）
  ├── 子2-2：空气（只有上限）
  ├── 子2-3：水位（上下限各一行）
  └── 子2-4：PH（上下限各一行）

主页面3（手动控制）
  ├── 子3-1：加热
  ├── 子3-2：加水
  ├── 子3-3：排水
  └── 子3-4：增氧
```

### 7.3 按键功能矩阵

| 按键 | 主页面1 | 主页面2（阈值） | 主页面3（手动） |
|------|---------|----------------|----------------|
| KEY1 (PA8) | → 主页面2 | → 主页面3 | → 主页面1 |
| KEY2 (PB3) | 子页面切换(1-1→1-2→1-3) | 子页面切换(2-1→2-2→2-3→2-4) | 手动模式切换继电器，自动模式无效 |
| KEY3 (PB4) | 无功能 | 选中字段+1 | 切换自动/手动模式 |
| KEY4 (PB8) | 无功能 | 选中字段-1 | 手动模式下切换继电器ON/OFF |
| KEY5 (PA4) | 无功能 | 切换上限/下限（空气页自动选中上限） | 无功能 |

### 7.4 阈值设置流程

```
进入主页面2（阈值设置）
│
├── KEY2 切换参数类（温度 → 空气 → 水位 → PH，循环）
│
├── KEY5 切换选中上限还是下限
│   ├── 空气页：只有上限，自动选中，KEY5 无效
│   └── 其他页：上限
