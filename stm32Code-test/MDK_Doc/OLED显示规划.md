# 智能鱼缸系统 — OLED 显示规划

> 版本：V2.0 | 日期：2026-05-04
> 屏幕：SSD1306 0.96" 128×64 I2C（PA11=SDA, PA12=SCL）
> 字体：6×12（宋体，12×12 点阵，列行式 逆向 阴码）
> 可用行：row2 / row4 / row6（每行 12px 高，共 3 行）
> 每行最大字符：约 21 个 ASCII 或 10 个汉字

---

## 一、页面架构

```
+---------------------------------------------+
|                  OLED 128×64                 |
|                                             |
|   +---------+   +---------+   +---------+  |
|   | 主页面1  |   | 主页面2  |   | 主页面3  |  |
|   | 数据显示 |   | 阈值设置 |   | 手动控制 |  |
|   +----+----+   +----+----+   +----+----+  |
|        |             |             |        |
|   +----+----+   +----+----+   +----+----+  |
|   |子1-1    |   |子2-1    |   |子3-1    |  |
|   |水温+PH  |   |温度     |   |加热     |  |
|   |---------|   |---------|   |---------|  |
|   |子1-2    |   |子2-2    |   |子3-2    |  |
|   |水位+空气|   |空气     |   |加水     |  |
|   |---------|   |---------|   |---------|  |
|   |子1-3    |   |子2-3    |   |子3-3    |  |
|   |排水/增氧|   |水位     |   |排水     |  |

|                 |子2-4    |   |子3-4    |  |
|                 |PH       |   |增氧     |  |
|                 +---------+   +---------+  |
+---------------------------------------------+
```

### 导航逻辑

| 按键 | 引脚 | 功能 |
|------|------|------|
| KEY1 | PA6 | 主页面切换：1->2->3->1（循环），子页面归零 |
| KEY2 | PA7 | 子页面切换：在当前主页面内循环 |
| KEY3 | PB0 | 阈值选中项+1 / 切换自动<->手动模式 |
| KEY4 | PA3 | 阈值选中项-1 / 手动继电器ON/OFF |
| KEY5 | PA4 | 阈值切换上限/下限 |

### 页码显示

右上角显示页码格式 `"N/M"`（N=主页面序号, M=当前主页面下子页面总数）。

## 二、主页面 1 — 数据显示

展示传感器实时数据和系统运行状态。

### 子页面 1-1：水温 + PH

```
+------------------------------+
| 水温:25.5C       PH:7.2     |  row2
|                              |  row4 (空)
| W+   自动        喂食: 30s  |  row6
+------------------------------+
     右上角: 1/3
```

- row2：左侧水温数值，右侧 PH 数值
- row6：左侧 WiFi 状态（W+/W-），中间运行模式（自动/手动），右侧喂食倒计时（喂食中显示秒数，空闲显示"--"）

### 子页面 1-2：水位 + 空气质量

```
+------------------------------+
| 水位: 65%        空气: 230   |  row2
|                              |  row4 (空)
| 加热:OFF  加水:OFF           |  row6
+------------------------------+
     右上角: 2/3
```

- row2：左侧水位百分比，右侧空气质量数值
- row6：加热/加水继电器状态

### 子页面 1-3：排水/增氧 + ALM/模式

```
+------------------------------+
| 排水:OFF  增氧:ON            |  row2
| ALM:ON    模式:手动          |  row4
|                              |  row6 (空)
+------------------------------+
     右上角: 3/3
```

- row2：排水/增氧继电器状态
- row4：报警使能状态 + 当前运行模式

### 子页面切换方式

- 按 KEY2 在子页面 1-1 -> 1-2 -> 1-3 -> 1-1 之间循环
- 按 KEY1 跳转到主页面 2（子页面归零）

## 三、主页面 2 — 阈值设置

展示和调节各传感器的报警阈值。子页面分 4 组，每组一个参数类。
选中字段前显示 `">"` 光标，KEY5 切换上下限。

### 子页面 2-1：温度阈值

```
+------------------------------+
| >温度                         |  row2
|   下限:20.0  上限:30.0 C     |  row4
|                              |  row6
+------------------------------+
     右上角: 1/4
```

- `">"` 标记当前选中（row2 左侧参数标签）
- KEY5 切换选中下限/上限（光标在 row4 的下限/上限间移动）
- KEY3 短按：选中项 +1
- KEY4 短按：选中项 -1
- 上下限互锁保护

### 子页面 2-2：空气质量阈值

```
+------------------------------+
| >空气                         |  row2
|   上限:<500                   |  row4
|                              |  row6
+------------------------------+
     右上角: 2/4
```

- 空气只有上限，自动选中上限，KEY5 无效
- KEY3：上限 +10
- KEY4：上限 -10

### 子页面 2-3：水位阈值

```
+------------------------------+
| >水位                         |  row2
|   下限:40  上限:80 %         |  row4
|                              |  row6
+------------------------------+
     右上角: 3/4
```

- KEY5 切换选中下限/上限
- KEY3：选中项 +1
- KEY4：选中项 -1

### 子页面 2-4：PH 阈值

```
+------------------------------+
| >PH                           |  row2
|   下限:6.5  上限:8.5         |  row4
|                              |  row6
+------------------------------+
     右上角: 4/4
```

- KEY5 切换选中下限/上限
- KEY3：选中项 +0.1
- KEY4：选中项 -0.1

### 子页面切换方式

- 按 KEY2 在子页面 2-1 -> 2-2 -> 2-3 -> 2-4 -> 2-1 之间循环
- 仅在主页面 2 下 KEY3/KEY4/KEY5 才有效

## 六、全局变量定义

```c
// 由 Flag_StructType 管理
uint8_t currentPage;       // 主页面 0=数据, 1=阈值, 2=手动
uint8_t subPage;           // 子页面索引
uint8_t thresholdField;    // 阈值: 0=下限, 1=上限
uint8_t thresholdIndex;    // 当前选中参数索引
```

### 状态机

```
上电 -> 启动画面(2s) -> 主页面1-子页面1-1

KEY1 按下:
  currentPage = (currentPage + 1) % 3
  subPage = 0

KEY2 按下:
  if (currentPage == 0) subPage = (subPage + 1) % 3
  if (currentPage == 1) subPage = (subPage + 1) % 4
  if (currentPage == 2 && runMode == 1) subPage = (subPage + 1) % 4

KEY3 按下:
  if (currentPage == 1) 当前选中字段值 +1
  if (currentPage == 2) runMode 切换 (自动<->手动)

KEY4 按下:
  if (currentPage == 1) 当前选中字段值 -1
  if (currentPage == 2 && runMode == 1) 选中继电器 ON/OFF

KEY5 按下:
  if (currentPage == 1 && subPage != 1) thresholdField 切换 (上下限)
  // subPage==1(空气) 只有上限，KEY5 无效
```

## 八、显示刷新机制

- `Display_Refresh()` 在 `Timing_1s()` 中调用
- 根据 `currentPage` 和 `subPage` 选择对应的显示函数
- 阈值页面根据 `thresholdField` 和 `thresholdIndex` 确定 `">"` 光标位置
- 手动页面根据 `runMode` 决定显示内容（自动模式->"自动模式！"，手动模式->继电器控制）
