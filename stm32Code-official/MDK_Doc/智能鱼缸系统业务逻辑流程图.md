## 2. 系统启动流程

系统上电后，依次完成时钟配置、外设初始化、默认参数加载、启动画面显示，最后进入主循环等待中断调度。

```
┌─────────────────────────────────┐
│         上电 / 复位              │
└───────────────┬─────────────────┘
                ▼
┌─────────────────────────────────┐
│  时钟与中断基础配置              │
│  · 系统时钟 → 72MHz             │
│  · NVIC 中断优先级分组           │
│  · SysTick 1ms 节拍             │
└───────────────┬─────────────────┘
                ▼
┌─────────────────────────────────┐
│  外设初始化                      │
│  · OLED (PA11/PA12 I2C)         │
│  · DS18B20 (PB13 1-Wire)        │
│  · ADC (PA0/PA1/PA4 三通道)     │
│  · 4路继电器 (PB12/PB14/PB15/PA15)│
│  · 舵机 (PA6 TIM3 PWM)          │
│  · WiFi ESP-01S (PA2/PA3 USART2)│
│  · 按键 (PA8/PB3/PB4/PB8/PB1)  │
│  · 蜂鸣器+LED (PB9)             │
└───────────────┬─────────────────┘
                ▼
┌─────────────────────────────────┐
│  加载系统默认参数                │
│  · 运行模式 → 自动              │
│  · 报警使能 → 开启              │
│  · 喂食倒计时 → 设定默认间隔    │

└───────────────┬─────────────────┘

┌─────────────────────────────────┐
│  OLED 显示启动画面              │

│  · 延时约 2 秒                  │
└───────────────┬─────────────────┘
                ▼
┌─────────────────────────────────┐
│  TIM2 定时器中断调度启动         │
│  · 配置 TIM2 为 1ms 中断周期    │

└─────────────────────────────────┘
```

**要点说明**：
- 主循环只处理非周期性事件（WiFi 接收、按键响应）
- 所有周期性采集、控制、显示任务由 TIM2 中断调度完成
- 系统为裸机架构，无 RTOS，通过中断+标志位实现多任务

## 3. TIM2 中断调度时序

TIM2 以 1ms 为基本节拍，通过全局计数器取模运算，将任务分配到不同时间片执行。

### 3.1 调度时间轴

```
 ──┬────┬────┬────┬────┬────┬────┬────┬────┬────┬────┬────┬───→ 时间
   0    1    2    3    4    5   ...  10  ...   50  ...  500 ... 1000
   │    │    │    │    │    │        │        │        │       │
   ▼    ▼    ▼    ▼    ▼    ▼        ▼        ▼        ▼       ▼
  BEEP LED  ──   ──  ADC  ADC     滤波     按键    传感器   显示
  1ms  2ms       5ms            10ms     50ms   控制报警  喂食WiFi
```

### 3.2 各周期任务一览

| 周期 | 任务函数 | 具体功能 |
|------|----------|----------|
| 1ms | BEEP 状态机 | 蜂鸣器响/停节奏控制 |
| 2ms | LED 扫描 | LED 闪烁节奏控制 |
| 5ms | ADC 轮询 | PA0/PA1/PA4 三通道轮流采集 |
| 10ms | 数据滤波 | 传感器中间值处理与平滑 |
| 50ms | 按键扫描 | 5 路按键消抖与事件检测 |
| 500ms | 传感器+控制+报警 | 温度/水位/PH/空气采集 → 自动控制 → 报警检测 |
| 1s | 显示+喂食+WiFi | OLED 刷新 + 喂食状态机 + WiFi 数据上报 |

**调度逻辑**：每个中断到来时 `g_tick_ms++`，各周期任务通过 `g_tick_ms % N == 0` 判断是否执行。同一中断内任务按固定顺序串行执行，优先级：BEEP > LED > ADC > 滤波 > 按键 > 传感器/控制/报警 > 显示/喂食/WiFi。

## 4. 数据流总览

这是整个系统的数据流向总图，展示从传感器采集到显示、控制、报警的完整链路。

```
┌─────────────────────────────────────────────────────────────────┐
│                         传感器采集层                             │
│                                                                 │
│  DS18B20 ──1-Wire──→ 水温值 (°C)                               │
│  MQ-135  ───ADC───→ 空气质量 (0~4095)                          │
│  水位     ───ADC───→ 水位百分比 (0~100%)                        │
│  PH      ───ADC───→ PH 值 (0~14)                               │
└─────────────────────┬───────────────────────────────────────────┘
                      ▼
┌─────────────────────────────────────────────────────────────────┐
│                       全局数据变量                               │
│                                                                 │
│  waterTemp / waterLevel / phValue / airQuality                  │
│  tempLower / tempUpper / waterLevelMin / waterLevelMax          │
│  airQualityMax / phLower / phUpper                              │
│  runMode / feedCountdown / alarmEnable                          │
└───┬──────────┬──────────┬──────────┬──────────┬────────────────┘
    ▼          ▼          ▼          ▼          ▼
┌────────┐┌────────┐┌────────┐┌────────┐┌────────────┐
│ OLED   ││ 自动   ││ 报警   ││ WiFi   ││ 喂食       │
│ 显示   ││ 控制   ││ 检测   ││ 上报   ││ 控制       │
└────┬───┘└────┬───┘└────┬───┘└────┬───┘└─────┬──────┘
     │         │         │         │           │
     ▼         ▼         ▼         ▼           ▼
  128×64   继电器     蜂鸣器    ESP-01S     舵机SG90
  屏幕     开/关     LED闪烁    远程服务器   开/关3秒
```

**数据流向说明**：

1. **传感器 → 全局变量**：500ms 周期采集，结果写入全局变量
2. **全局变量 → OLED**：1s 周期读取并刷新屏幕
3. **全局变量 → 自动控制**：500ms 周期判断阈值，输出继电器控制信号
4. **全局变量 → 报警**：500ms 周期检测异常，触发蜂鸣器/LED
5. **全局变量 → WiFi**：1s 周期打包上报
6. **按键 → 全局变量**：用户操作修改页面/模式/阈值
7. **WiFi → 全局变量**：远程指令修改控制参数

## 5. 传感器采集流程

每 500ms 由 TIM2 中断触发一次完整采集，读取 4 路传感器数据并写入全局变量。

### 5.1 采集流程图

```
      Sensor_Read() 每500ms调用
              │
    ┌─────────┼─────────┬─────────────┐
    ▼         ▼         ▼             ▼
┌────────┐┌────────┐┌──────────┐┌──────────┐
│DS18B20 ││ MQ-135 ││ 水位     ││ PH       │
│PB13    ││ PA4    ││ PA1      ││ PA0      │
│1-Wire  ││ ADC_IN4││ ADC_IN1  ││ ADC_IN0  │
└───┬────┘└───┬────┘└────┬─────┘└────┬─────┘
    │         │          │           │
    ▼         ▼          ▼           ▼
 水温(°C)  空气质量   水位(%)     PH值
  float    uint16     uint8      float
    │         │          │           │
    ▼         ▼          ▼           ▼
┌─────────────────────────────────────────┐
│        全局数据变量 (统一存储)            │
│  waterTemp / airQuality / waterLevel    │
│  / phValue                              │
└─────────────────────────────────────────┘
```

### 5.2 各传感器采集说明

| 传感器 | 引脚 | 采集方式 | 数据转换 | 范围 |
|--------|------|----------|----------|------|
| DS18B20 | PB13 | 1-Wire 协议直接读取 | 芯片内部转换，直接输出 °C | -55 ~ +125°C |
| MQ-135 | PA4 (ADC1_IN4) | ADC 寄存器读取 | 原始 ADC 值 | 0 ~ 4095 |
| 水位 | PA1 (ADC1_IN1) | ADC 寄存器读取 | ADC × 100 / 4095 → 百分比 | 0 ~ 100% |
| PH | PA0 (ADC1_IN0) | ADC 寄存器读取 | ADC × 14.0 / 4095 → PH 值 | 0 ~ 14 |

**ADC 轮询机制**：TIM2 每 5ms 触发一次 ADC 轮询，三通道（PA0/PA1/PA4）轮流采集，10ms 周期进行中间值滤波平滑处理。500ms 周期时读取滤波后的稳定值。

## 6. 自动控制流程

每 500ms 由 TIM2 中断触发，系统读取传感器数据，与用户设定的阈值比较，自动控制 4 路继电器。仅在自动模式下生效。

### 6.1 控制总流程

```
       Auto_Control() 每500ms调用
                │
                ▼
        ┌───────────────┐
        │ 读取传感器数据  │
        │ waterTemp      │
        │ waterLevel     │
        │ airQuality     │
        └───────┬───────┘
                ▼
        ┌───────────────┐     否
        │ runMode == 自动 ├──────────→ 直接返回，不控制
        └───────┬───────┘
                │ 是
        ┌───────┴───────────────────────────┐
        ▼               ▼                   ▼
  ┌───────────┐  ┌─────────────┐  ┌──────────────┐
  │ 温度控制   │  │ 水位控制     │  │ 空气质量控制  │
  │ (滞环)    │  │ (区间判断)   │  │ (阈值开关)   │
  └─────┬─────┘  └──────┬──────┘  └──────┬───────┘
        │               │                │
        ▼               ▼                ▼
  relayHeat      relayDrain         relayOxygen
  ON / OFF       relayFill          ON / OFF
                 ON / OFF
```

### 6.2 温度控制（滞环控制）

温度控制采用滞环（迟滞）逻辑，防止继电器在阈值附近频繁切换。

```
  温度轴 ▲
         │
  tempUpper ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─  relayHeat = OFF（停止加热）
         │
         │       ┌─────────────┐
         │       │  安全区间    │
         │       │  维持当前状态 │
         │       └─────────────┘
         │
  tempLower ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─  relayHeat = ON（开始加热）
         │
         └──────────────────────────→ 温度值

  工作过程：
  ① 水温从高降低 → 低于 tempLower → 加热继电器开启
  ② 水温逐渐上升 → 高于 tempUpper → 加热继电器关闭
  ③ 在上下限之间 → 保持当前状态不变（滞环效果）
```

### 6.3 水位控制（区间判断）

水位控制根据当前水位百分比与设定的上下限比较，决定加水或排水。

```
  水位% ▲
        │
   100% ┼ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─
        │
  waterLevelMax ─ ─ ─ ─ ─ ─ ─ ─ ─ ─  relayDrain = ON（排水）
        │                              relayFill = OFF
        │
        │        ┌──────────────┐
        │        │   安全区间    │
        │        │ relayDrain=OFF│
        │        │ relayFill=OFF │
        │        └──────────────┘
        │
  waterLevelMin ─ ─ ─ ─ ─ ─ ─ ─ ─ ─  relayFill = ON（加水）
        │                              relayDrain = OFF
        │
     0% ┼ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─
        └──────────────────────────→ 水位值
```

### 6.4 空气质量控制（阈值开关）

空气质量控制逻辑简单，超过上限开启增氧，低于上限关闭。

```
  空气质量 ▲
           │
  airQualityMax ─ ─ ─ ─ ─ ─ ─ ─ ─ ─  relayOxygen = ON（开始增氧）
           │
           │        ┌──────────────┐
           │        │  正常区间     │
           │        │ relayOxygen=OFF│
           │        └──────────────┘
           │
           └──────────────────────────→ 空气质量值

  逻辑：airQuality > airQualityMax → relayOxygen = ON
        airQuality ≤ airQualityMax → relayOxygen = OFF
```

### 6.5 继电器与引脚对应关系

| 控制对象 | 继电器引脚 | 控制条件 | 有效电平 |
|----------|-----------|----------|----------|
| 加热棒 | PB12 | waterTemp < tempLower → ON | 高电平 |
| 加水泵 | PB14 | waterLevel < waterLevelMin → ON | 高电平 |
| 排水泵 | PB15 | waterLevel > waterLevelMax → ON | 高电平 |
| 增氧泵 | PA15 | airQuality > airQualityMax → ON | 高电平 |

## 7. 报警逻辑流程

每 500ms 检测一次，当传感器数据超过安全阈值时，触发蜂鸣器和 LED 交替闪烁报警。

### 7.1 报警触发流程

```
       Alarm_Check() 每500ms调用
                │
                ▼
       ┌────────────────┐     否
       │ alarmEnable 开启 ├────────→ 直接返回
       └────────┬───────┘
                │ 是
                ▼
       ┌────────────────┐     否
       │ 存在报警事件？   ├────────→ 清除报警状态，蜂鸣器/LED 关闭
       └────────┬───────┘
                │ 是
                ▼
       ┌────────────────┐
       │ 进入报警状态    │
       │ · 蜂鸣器开启    │
       │ · LED 开启      │
       │ · 重置报警计时器 │
       └────────┬───────┘
                ▼
       ┌────────────────────────────────┐
       │         报警节奏控制             │
       │                                │
       │  0s         0.5s       3s      │
       │  ├────响────┤----停----┤→ 循环  │
       │  蜂鸣器ON   蜂鸣器OFF          │
       │  LED ON     LED OFF            │
       └────────────────────────────────┘
```

### 7.2 报警条件一览

报警事件由 Auto_Control() 在每次自动控制判断时同步检测，满足任一条件即标记报警事件：

| 报警条件 | 触发描述 |
|----------|----------|
| 温度过低 | waterTemp 低于安全温度下限 |
| 温度过高 | waterTemp 高于安全温度上限 |
| 水位过低 | waterLevel 低于最低安全水位 |
| 水位过高 | waterLevel 高于最高安全水位 |
| 空气质量超标 | airQuality 高于安全上限 |

**报警解除**：当 Auto_Control() 检测到所有参数回到安全区间，不再标记报警事件，蜂鸣器和 LED 自动静默。

## 8. 喂食控制流程

喂食可通过按键手动触发，也可通过倒计时自动触发。舵机打开 3 秒后自动关闭。

### 8.1 喂食状态机

```
┌──────────────┐         触发          ┌──────────────┐
│              │  (按键或倒计时归零)    │              │
│    待机状态   ├────────────────────→  │   喂食中     │
│              │                       │  舵机打开90°  │
│ · 倒计时递减  │                       │ · 计时器=0    │
│ · 等待触发    │                       │ · 计时器++    │
└──────────────┘                       └──────┬───────┘
      ▲                                       │
      │                                       │ 3秒后
      │         ┌──────────────┐              │
      │         │              │◄─────────────┘
      └─────────┤  舵机关闭    │
                │  重置倒计时   │
                │              │
                └──────────────┘
```

### 8.2 触发方式

```
  ┌──────────────────────────────┐
  │        喂食触发源             │
  └──────┬──────────────┬────────┘
         │              │
         ▼              ▼
  ┌──────────────┐ ┌───────────────┐
  │  手动触发     │ │  自动触发      │
  │              │ │               │
  │ KEY5 长按2秒 │ │ 倒计时归零     │
  │ (PB1)       │ │ 自动执行       │
  └──────┬───────┘ └───────┬───────┘
         │                 │
         └────────┬────────┘
                  ▼
         ┌──────────────┐
         │  设置触发标志  │
         └──────┬───────┘
                ▼
         Feed_Control() 每1s检查
```

### 8.3 时间参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 舵机打开角度 | 90° | 通过 TIM3_CH1 (PA6) PWM 控制 |
| 喂食持续时间 | 3 秒 | 舵机打开后自动关闭 |
| 默认倒计时间隔 | 用户设定 | 每次喂食完成后重置 |

## 9. 按键业务流程

5 个按键在不同页面下具有不同功能。按键扫描每 50ms 执行一次，采用连续 3 次一致确认的消抖策略。

### 9.1 按键扫描机制

```
      Key_Scan() 每50ms调用
              │
              ▼
     ┌────────────────┐
     │ 读取 5 路 GPIO  │
     │ KEY1~KEY5 电平  │
     └────────┬───────┘
              ▼
     ┌────────────────┐
     │ 消抖判断        │
     │ 连续3次一致？   │──── 否 ──→ 忽略，返回
     └────────┬───────┘
              │ 是
              ▼
     ┌────────────────┐
     │ 判断按键事件    │
     │ · 短按          │
     │ · 长按(≥2秒)    │
     └────────┬───────┘
              ▼
     ┌────────────────┐
     │ 写入全局事件变量│
     └────────┬───────┘
              ▼
     主循环检测到事件标志
     → Key_Event_Process() 处理
```

### 9.2 页面导航架构

系统共 3 个主页面，每个主页面包含若干子页面，通过 KEY1 和 KEY2 切换。

```
KEY1 切换主页面 (循环)
┌──────────┐    ┌──────────┐    ┌──────────┐
│ 主页面1   │───→│ 主页面2   │───→│ 主页面3   │──┐
│ (数据显示) │    │ (阈值设置) │    │ (手动控制) │  │
└──────────┘    └──────────┘    └──────────┘  │
     ▲                                         │
     └─────────────────────────────────────────┘

KEY2 切换子页面 (循环)
┌─────────────────────────────────────────────────────────┐
│ 主页面1                                                 │
│  ├── 子1-1: 水温 + PH + 状态栏(WiFi/模式/喂食)         │
│  ├── 子1-2: 水位 + 空气 + 加热/加水状态                 │
│  └── 子1-3: 排水/增氧 + ALM/模式                        │
├─────────────────────────────────────────────────────────┤
│ 主页面2                                                 │
│  ├── 子2-1: 温度 (上下限)                               │
│  ├── 子2-2: 空气 (上限)                                 │
│  ├── 子2-3: 水位 (上下限)                               │
│  └── 子2-4: PH (上下限)                                 │
├─────────────────────────────────────────────────────────┤
│ 主页面3                                                 │
│  ├── 子3-1: 加热                                        │
│  ├── 子3-2: 加水                                        │
│  ├── 子3-3: 排水                                        │
│  └── 子3-4: 增氧                                        │
└─────────────────────────────────────────────────────────┘
```

### 9.3 按键功能矩阵

| 按键 | 引脚 | 主页面1 (数据) | 主页面2 (阈值) | 主页面3 (手动) |
|------|------|---------------|---------------|---------------|
| **KEY1** | PA8 | → 切到主页面2 | → 切到主页面3 | → 切到主页面1 |
| **KEY2** | PB3 | 子页面循环切换 | 子页面循环切换 | 手动模式：子页面切换；自动模式：无效 |
| **KEY3** | PB4 | 无功能 | 选中值 +1 | 短按：自动↔手动切换；长按2s：同上 |
| **KEY4** | PB8 | 无功能 | 选中值 -1 | 手动模式：继电器 ON/OFF 切换 |
| **KEY5** | PB1 | 无功能 | 短按：上下限切换；长按2s：喂食 | 无功能 |

### 9.4 阈值设置流程

```
      进入主页面2（阈值设置）
              │
     ┌────────┴────────┐
     ▼                 ▼
  KEY2 切换         KEY5 切换
  参数类别          上限/下限
  温度→空气        (空气页只有
  →水位→PH         上限,KEY5无效)
     │                 │
     └────────┬────────┘
              ▼
     ┌────────────────┐
     │  当前选中字段    │
     │  用 "> " 光标   │
     │  标记显示       │
     └────────┬───────┘
              │
     ┌────────┴────────┐
     ▼                 ▼
  KEY3: +1          KEY4: -1
     │                 │
     └────────┬────────┘
              ▼
     ┌────────────────┐
     │  上下限互锁保护  │
     │  下限 ≤ 上限    │
     └────────────────┘
```

### 9.5 手动控制流程

```
      进入主页面3（手动控制）
              │
              ▼
     ┌────────────────┐
     │ runMode 是什么？ │
     └───┬─────────┬───┘
         │         │
    自动模式    手动模式
         │         │
         ▼         ▼
  ┌────────────┐ ┌────────────────────┐
  │ 显示       │ │ KEY2: 切换继电器   │
  │ "自动模式！"│ │ 加热→加水→排水→增氧│
  │            │ │                    │
  │ KEY2: 无效 │ │ KEY3: 切回自动模式  │
  │ KEY4: 无效 │ │ (同时关闭所有继电器)│
  │            │ │                    │
  │ KEY3: 切换 │ │ KEY4: 选中继电器   │
  │ →手动模式  │ │ ON / OFF 切换     │
  └────────────┘ └────────────────────┘
```

**模式切换安全机制**：从自动切到手动时，所有继电器自动归零（全部关闭），防止手动模式下出现意外的执行器动作。

## 11. WiFi 通信流程

ESP-01S 通过 USART2 与 STM32 通信，采用中断接收 + 主循环处理的架构。

### 11.1 数据接收流程

```
┌─────────────────────┐
│  USART2 RX 中断      │
│  (PA3 接收字节)      │
└─────────┬───────────┘
          ▼
┌─────────────────────┐
│  写入环形缓冲区      │
│  g_wifi_rx_buf[]    │
└─────────┬───────────┘
          ▼
┌─────────────────────┐
│  g_wifi_rx_flag = 1 │
└─────────┬───────────┘
          │
          │  主循环检测
          ▼
┌─────────────────────┐
│  清除接收标志        │
└─────────┬───────────┘
          ▼
┌─────────────────────┐
│  解析完整数据帧      │
│  · AT 指令响应解析   │
│  · 远程控制参数提取   │
└─────────┬───────────┘
          ▼
┌─────────────────────┐
│  执行对应操作        │
│  · 更新控制参数      │
│  · 回传传感器数据    │
└─────────────────────┘
```

### 11.2 数据上报流程

每 1 秒由 TIM2 调度触发，将传感器数据打包通过 ESP-01S 上报。

```
      WiFi_Report() 每1s调用
              │
              ▼
     ┌────────────────┐
     │ 读取全局数据    │
     │ waterTemp       │
     │ waterLevel      │
     │ phValue         │
     │ airQuality      │
     │ runMode         │
     │ 各继电器状态     │
     └────────┬───────┘
              ▼
     ┌────────────────┐
     │ 组装数据帧      │
     │ (JSON/自定义格式)│
     └────────┬───────┘
              ▼
     ┌────────────────┐
     │ USART2 发送     │
     │ → ESP-01S      │
     │ → 远程服务器    │
     └────────────────┘
```

### 11.3 WiFi 通信引脚

| 功能 | 引脚 | 说明 |
|------|------|------|
| TX (发送) | PA2 | STM32 → ESP-01S |
| RX (接收) | PA3 | ESP-01S → STM32 |
| 接口 | USART2 | 波特率按 ESP-01S 配置 |

### 关键交互链路说明

| 链路 | 数据流 | 触发周期 | 说明 |
|------|--------|----------|------|
| 传感器 → 全局变量 | 原始数据 → 工程值 | 500ms | 4 路传感器采集并转换 |
| 全局变量 → OLED | 当前值 → 屏幕刷新 | 1s | 读取并绘制到屏幕 |
| 全局变量 → 自动控制 | 当前值 vs 阈值 → 继电器 | 500ms | 滞环/区间判断 |
| 全局变量 → 报警 | 超限检测 → 蜂鸣器 | 500ms | 异常时触发声光报警 |
| 全局变量 → WiFi | 打包数据 → 上报 | 1s | 远程监控 |
| 按键 → 全局变量 | 用户操作 → 参数修改 | 50ms 扫描 | 页面/模式/阈值修改 |
| WiFi → 全局变量 | 远程指令 → 参数修改 | 事件驱动 | 远程控制 |
| 自动控制 → 报警 | 超限标记 → 报警事件 | 500ms | 控制与报警联动 |
