## 3. 函数调用关系

### 3.1 系统启动调用链

```
main()
 ├── NVIC_PriorityGroupConfig(NVIC_PriorityGroup_4)
 ├── delay_init(72)
 ├── GENERAL_TIM_Init()              → TIM2 配置，1ms 中断
 ├── LED_Init()
 ├── Beep_Init()
 ├── KEY_GPIO_Config()
 ├── OLED_Init()                     → PA11/PA12 I2C 初始化
 ├── DS18B20_Init()                  → PB13 初始化
 ├── ADC_Polling_Init()              → PA0/PA1/PA4 ADC 配置
 ├── Debug_USART1_Init()             → 调试串口
 ├── ESP01S_Init()                   → USART2 + ESP-01S AT 配置
 ├── GPIO 继电器初始化               → PB12/PB14/PB15/PA15
 ├── GPIO 舵机初始化                 → PA6 TIM3_CH1
 ├── 全局变量初始化 (Flag + Record)
 ├── TIM_Cmd(TIM3, ENABLE)           → 启动舵机 PWM
 ├── Servo_SetAngle(0)               → 舵机归零
 ├── OLED_ShowStart()                → 启动画面
 ├── delay_ms(2000)
 └── while(1) 主循环
```

### 3.2 主循环调用链

```
while(1)
 ├── DS18B20 温度读取（每 ~1s）
 │    └── DS18B20_GetTemperture() → Record.waterTemp
 ├── 继电器互斥安全检查（Fill/Drain）
 ├── GPIO 继电器输出
 │    └── GPIO_WriteBit() × 4
 ├── OLED 页面切换检测 + 刷新
 │    └── OLED_Show_Page(currentPage)
 ├── ESP01S_Process()               → WiFi 数据接收处理
 ├── ESP01S_SendSensorData()        → 传感器数据上报（每 ~3s）
 └── delay_ms(100)
```

### 3.3 TIM2 中断调用链

```
TIM2_IRQHandler()
 ├── Timing_1ms()                   → KEY_DrvScan() 按键底层扫描
 ├── Timing_2ms()                   → (空)
 ├── Timing_5ms()                   → ADC 三通道轮询采集
 │    ├── 水位 PA1 → Record.waterLevel
 │    ├── PH PA0  → Record.phValue
 │    └── 空气 PA4 → Record.airQuality
 ├── Timing_10ms()                  → (空)
 ├── Timing_50ms()                  → KEY_Scan() 按键消抖 + 事件生成
 ├── Timing_500ms()
 │    ├── 自动控制逻辑（仅自动模式）
 │    │    ├── 温度滞环控制 → Flag.relayHeat
 │    │    ├── 水位区间控制 → Flag.relayFill / Flag.relayDrain
 │    │    └── 空气质量控制 → Flag.relayOxygen
 │    └── 报警检查 → BEEP_Blink() / BEEP_Off()
 └── Timing_1s()
      ├── 手动模式安全超时（60s 自动关闭继电器）
      ├── 喂食控制（倒计时 + 舵机动作）
      └── Servo_SetAngle()
```

```
             │    │    │    │    │    │         │         │         │         │

             │    │    │    │    │    │         │         │         │         │

             │    │    │    │    │    │         │         │         │         │

             │    │    │    │    │    │         │         │         │         │

             │    │    │    │    │    │         │         │         │         │

```

### 4.2 各周期任务详解

| 周期 | 函数 | 执行内容 | 耗时估算 |
|------|------|----------|----------|
| 1 ms | `Timing_1ms()` | `KEY_DrvScan()` — 读取 5 个按键 GPIO 电平，写入按键缓冲区 | < 10 μs |
| 2 ms | `Timing_2ms()` | 保留（空函数） | — |
| 5 ms | `Timing_5ms()` | ADC 三通道轮询（实际每 15ms 完成一轮）：水位→PH→空气质量 | ~200 μs |
| 10 ms | `Timing_10ms()` | 保留（空函数） | — |
| 50 ms | `Timing_50ms()` | `KEY_Scan()` — 连续 3 次消抖确认，生成按键事件 | < 20 μs |
| 500 ms | `Timing_500ms()` | 自动控制逻辑（温度/水位/空气质量）+ 报警判断 | < 50 μs |
| 1 s | `Timing_1s()` | 手动模式安全超时、喂食倒计时、舵机控制 | < 50 μs |

### 4.3 中断优先级

| 中断 | 抢占优先级 | 子优先级 | 说明 |
|------|-----------|----------|------|
| TIM2 | 2 | 0 | 系统调度心跳 |
| USART2 (WiFi) | — | — | 串口接收中断 |
| USART1 (Debug) | — | — | 调试串口 |

## 5. 全局数据结构

### 5.1 Flag_StructType（系统标志位）

定义于 `MDK_APP/MyTypedef.h`

```c
typedef struct
{
    uint8_t    currentPage;       // Current main page: 0=Home, 1=Threshold, 2=Manual
    uint8_t    subPage;           // Current sub page
    uint8_t    thresholdField;    // 0=select lower, 1=select upper
    uint8_t    thresholdIndex;    // Current selected threshold param index 0-6
    uint8_t    alarmEnable;       // Alarm: 0=off, 1=on
    uint8_t    feeding;           // Feed status: 0=idle, 1=feeding
    uint8_t    relayHeat;         // Heat relay state
    uint8_t    relayFill;         // Fill relay state
    uint8_t    relayDrain;        // Drain relay state
    uint8_t    relayOxygen;       // Oxygen relay state
    uint8_t    sensorError;       // Error flags: bit0=DS18B20, bit1=ADC
    uint16_t   manualTimeout;     // Manual safety timeout (seconds)
} Flag_StructType;
```

**标志位操作规则**：
- `currentPage` / `subPage`：由按键事件修改，OLED 显示读取
- `relayXxx`：自动模式由 `Timing_500ms()` 修改；手动模式由按键修改
- `sensorError`：DS18B20 读取异常时置位 bit0
- `manualTimeout`：手动模式下继电器开启后递减，归零自动关闭所有继电器

### 5.2 Record_StructType（传感器数据与阈值）

定义于 `MDK_APP/MyTypedef.h`

```c
typedef struct
{
    float      waterTemp;         // Water temperature °C
    float      phValue;           // pH value 0.0~14.0
    uint8_t    waterLevel;        // Water level 0~100%
    uint16_t   airQuality;        // Air quality (processed value 0~20)
    uint8_t    runMode;           // 0=Auto, 1=Manual
    int16_t    feedCountdown;     // Feed countdown (sec)
    uint16_t   feedInterval;      // Feed interval (sec), default 30

    // Thresholds
    float      tempLower;         // Temperature lower limit (default 20.0)
    float      tempUpper;         // Temperature upper limit (default 35.0)
    uint16_t   airQualityMax;     // Air quality upper limit (default 12)
    float      phLower;           // PH lower limit (default 4.0)
    float      phUpper;           // PH upper limit (default 8.0)
    uint8_t    waterLevelMin;     // Water level lower limit % (default 50)
    uint8_t    waterLevelMax;     // Water level upper limit % (default 70)
} Record_StructType;
```

**数据读写规则**：

| 字段 | 写入者 | 读取者 | 周期 |
|------|--------|--------|------|
| waterTemp | main.c DS18B20 读取 | OLED / 报警 / WiFi 上报 | ~1s |
| phValue | Timing_5ms() ADC | OLED / 报警 / WiFi 上报 | 15ms |
| waterLevel | Timing_5ms() ADC | OLED / 报警 / WiFi 上报 | 15ms |
| airQuality | Timing_5ms() ADC | OLED / 报警 / WiFi 上报 | 15ms |
| runMode | 按键 / WiFi 命令 | 自动控制 / OLED | — |
| feedCountdown | Timing_1s() | OLED / WiFi 上报 | 1s |
| relayXxx | 自动控制 / 按键 / WiFi | GPIO 输出 / OLED / WiFi | 100ms |

## 7. 主循环业务逻辑

### 7.1 main.c 主循环流程

```
while(1)
{
    ① DS18B20 温度读取（每 ~1s, 含断线检测）
       └── 有效值 → Record.waterTemp
       └── 异常值 → Flag.sensorError |= 0x01, 保持上次值
    
    ② 继电器互斥安全检查
       └── Fill + Drain 同时 ON → Drain 优先, Fill 清零
    
    ③ GPIO 继电器输出
       └── PB12(加热) PB14(加水) PB15(排水) PA15(增氧)
    
    ④ OLED 页面切换检测 + 刷新
       └── curPage = currentPage * 10 + subPage
       └── 页面变化 → OLED_Clr_Screen() + OLED_Show_Page()
    
    ⑤ ESP01S_Process() — WiFi 数据接收处理
    
    ⑥ 传感器数据上报（每 ~3s）
       └── 新连接时立即上报一次
       └── ESP01S_SendSensorData()
    
    ⑦ delay_ms(100) — 100ms 主循环周期
}
```

### 7.2 自动控制逻辑（Timing_500ms）

仅在 `Record.runMode == 0`（自动模式）下执行：

```
温度控制（滞环）:
    if waterTemp < tempLower  → relayHeat = 1 (开加热)
    if waterTemp > tempUpper  → relayHeat = 0 (关加热)
    中间区间 → 保持不变

水位控制（区间）:
    if waterLevel > waterLevelMax → relayDrain=1, relayFill=0 (排水)
    if waterLevel < waterLevelMin → relayFill=1, relayDrain=0 (加水)
    安全区间 → relayFill=0, relayDrain=0

空气质量控制（阈值）:
    if airQuality < airQualityMax → relayOxygen=1 (开增氧)
    else → relayOxygen=0 (关增氧)
```

## 8. 中断优先级配置

### 8.1 NVIC 分组

采用 `NVIC_PriorityGroup_4`：4 位抢占优先级，0 位子优先级。

### 8.2 中断源配置

| 中断源 | 抢占优先级 | 子优先级 | 说明 |
|--------|-----------|----------|------|
| TIM2 | 2 | 0 | 系统调度心跳（1ms） |
| USART1 | — | — | 调试串口（printf） |
| USART2 | — | — | ESP-01S 串口接收 |

### 8.3 设计原则

- TIM2 中断优先级设为 2，确保不阻塞更高优先级的通信中断
- 所有传感器读取（DS18B20）放在主循环而非中断中，避免中断阻塞
- ADC 采集在 TIM2 中断中执行（5ms 周期），但采用顺序轮询非 DMA
