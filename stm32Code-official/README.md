# 基于 STM32 的智能鱼缸监控系统

## 项目简介

本项目是一款基于 STM32F103C8T6 的智能鱼缸监控系统，通过传感器实时采集水质参数（温度、水位、PH、空气质量），自动控制加热、加水、排水、增氧等执行机构，并通过 OLED 本地显示与 WiFi（ESP-01S）远程上报实现双通道人机交互。

### 核心功能

- **温度监控**：DS18B20 采集水温，滞环控制加热继电器
- **水位监控**：模拟水位传感器，区间控制加水/排水继电器
- **PH 监测**：PH 传感器采集，越限报警
- **空气质量监测**：MQ-135 采集，超标自动增氧
- **OLED 显示**：SSD1306 128×64，3 主页面 × 多子页面
- **5 键交互**：独立按键导航、阈值设置、手动控制
- **自动喂食**：SG90 舵机定时/手动触发
- **WiFi 远程控制**：ESP-01S TCP Server，Android APP 连接控制
- **声光报警**：综合越限判断，蜂鸣器 + LED 循环报警

## 编译与烧录

### 开发环境

- IDE：Keil MDK-ARM v5
- 编译器：ARM Compiler v5/v6
- 目标芯片：STM32F103C8T6
- 调试器：ST-Link / J-Link

### 编译步骤

1. 使用 Keil MDK-ARM 打开 `MDK_Project/` 下的 `.uvprojx` 工程文件
2. 确认 Target 选择为 `STM32F103C8`
3. 点击 Build (F7) 编译
4. 编译成功后生成 `.hex` / `.bin` 文件

### 烧录步骤

1. 连接 ST-Link 调试器到 STM32 SWD 接口
2. Keil 中 Options for Target → Debug → 选择 ST-Link
3. 点击 Download (F8) 烧录
4. 或使用 ST-Link Utility 烧录 `.hex` 文件
