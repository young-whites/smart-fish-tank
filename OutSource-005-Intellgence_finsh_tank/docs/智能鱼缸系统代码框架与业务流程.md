```
├──────────────────────────────────────────────────────────────┤
│                    IPC 机制 (RT-Thread 内核)                  │
│  sem_sensor   sem_key   sem_wifi_rx                          │
│  mutex_oled   mutex_data                                     │
│  mb_alarm                                                    │
├──────────────────────────────────────────────────────────────┤
│                    驱动层 (drivers/)                          │
│  drv_gpio    drv_adc    drv_i2c    drv_pwm    drv_usart     │
├──────────────────────────────────────────────────────────────┤
│              RT-Thread 设备驱动框架 (components/drivers/)     │
├──────────────────────────────────────────────────────────────┤
│              RT-Thread 内核 (rt-thread/)                      │
│  调度器 / 时钟管理 / 内存管理 / IPC / 线程管理                │
├──────────────────────────────────────────────────────────────┤
│              ARM Cortex-M3 Core                              │
└──────────────────────────────────────────────────────────────┘
```

**架构对比（裸机 → RT-Thread）**：

| 裸机架构 | RT-Thread 架构 | 说明 |
|---------|---------------|------|
| TIM2 中断调度 (1ms) | RT-Thread 线程调度 | 硬定时器中断 → 内核软调度 |
| 全局变量直接访问 | mutex_data 互斥量保护 | 避免竞态条件 |
| Timing_10ms/500ms/1s | 独立线程 + rt_thread_mdelay() | 每个业务一个线程 |
| 中断中执行业务逻辑 | 线程中执行业务逻辑 | 中断只做信号量释放 |
| SysTick delay_ms() | rt_thread_mdelay() | 让出 CPU，非忙等 |
| HAL/寄存器直接操作 | rt_device 设备框架 | 统一 open/read/write/ioctl 接口 |

## 3. 线程架构

> 所有业务逻辑从 TIM2 中断回调迁移到独立 RT-Thread 线程

### 3.1 线程一览

| 线程名 | 优先级 | 栈大小 | 周期 | 职责 | 对应原函数 |
|--------|--------|--------|------|------|-----------|
| main | 10 | 2048 | - | 系统初始化、创建其他线程 | main() |
| t_sensor | 15 | 1024 | 500ms | 传感器数据采集 | Timing_10ms + Timing_1s(DS18B20) |
| t_control | 12 | 1024 | 500ms | 自动控制逻辑判断 + 继电器操作 | Timing_500ms(Auto_Control) |
| t_display | 18 | 1024 | 1s | OLED 刷新显示 | Timing_1s(OLED_Refresh) |
| t_key | 14 | 512 | 50ms | 按键扫描与事件处理 | Timing_1ms(KEY_DrvScan) + Timing_50ms(KEY_Scan) |
| t_alarm | 13 | 512 | 500ms | 报警逻辑判断 + 声光控制 | Timing_500ms(Alarm_Process) |
| t_feed | 16 | 512 | 1s | 喂食倒计时 + 舵机控制 | Timing_1s(Feed_Process) |
| t_wifi | 17 | 2048 | 事件驱动 | WiFi 通信（ESP-01S） | 串口中断处理 |

### 3.2 IPC 对象一览

| IPC 对象 | 类型 | 用途 | 生产者 | 消费者 |
|---------|------|------|--------|--------|
| sem_sensor | 信号量 | 传感器数据采集完成通知 | 定时器/传感器驱动 | t_control, t_alarm |
| sem_key | 信号量 | 按键事件通知 | 外部中断 ISR | t_key |
| sem_wifi_rx | 信号量 | WiFi 数据接收通知 | 串口 RX 中断 | t_wifi |
| mutex_oled | 互斥量 | OLED 显示资源保护 | t_display, t_key | t_display, t_key |
| mutex_data | 互斥量 | FishTank_DataStruct 数据保护 | t_sensor | t_control, t_alarm, t_display |
| mb_alarm | 邮箱 | 报警事件传递 | t_control | t_alarm |

### 3.3 优先级设计说明

```
数值越小优先级越高 (RT-Thread 默认)

  10 ─ main (最高，初始化后退出或降级)
  12 ─ t_control (自动控制，核心安全逻辑)
  13 ─ t_alarm (报警响应，安全相关)
  14 ─ t_key (按键响应，用户交互)
  15 ─ t_sensor (传感器采集)
  16 ─ t_feed (喂食控制)
  17 ─ t_wifi (网络通信)
  18 ─ t_display (显示刷新，最低优先级)
```

## 5. 系统启动流程

> 对应需求规格书 §9，从裸机 main() 改为 RT-Thread main 线程

```
上电/复位
 │
 ▼
RT-Thread 内核初始化
 ├─ SystemClock_Config()          # 系统时钟配置 (72MHz)
 ├─ rt_hw_interrupt_init()        # 中断向量表初始化
 ├─ rt_system_tick_init()         # 系统节拍初始化
 ├─ rt_system_heap_init()         # 堆内存初始化
 ├─ rt_system_scheduler_init()    # 调度器初始化
 └─ rt_system_timer_init()        # 系统定时器初始化
 │
 ▼
组件初始化
 ├─ finsh_system_init()           # FinSH 命令行组件
 └─ rt_device_driver_register()   # 设备驱动框架
 │
 ▼
main() 线程 (优先级 10, 栈 2048)
 ├─ 1. 外设初始化
 │   ├─ oled_init()               # OLED I2C (PA12/PA11)
 │   ├─ ds18b20_init()            # DS18B20 1-Wire (PB13)
 │   ├─ adc_init()                # ADC1 多通道 (PA0/PA1/PA4)
 │   ├─ relay_init()              # 4路继电器 (PB12/PB14/PB15/PA15)
 │   ├─ servo_init()              # 舵机 PWM (PA6 TIM3_CH1)
 │   └─ wifi_init()               # ESP-01S USART2 (PA2/PA3)
 │
 ├─ 2. 加载默认阈值
 │   ├─ SysFlag_Init()            # 阈值参数初始化
 │   ├─ RunMode = 0               # 默认自动模式
 │   ├─ Alarm_Enable = 1          # 默认报警开启
 │   └─ Countdown = FeedInterval  # 喂食倒计时初始化
 │
 ├─ 3. WiFi 连接（失败进入离线模式）
 │   └─ wifi_connect() → 超时则 RunMode = 0 离线运行
 │
 ├─ 4. 创建 IPC 对象
 │   ├─ rt_mutex_init(&mutex_data, "m_data", RT_IPC_FLAG_FIFO)
 │   ├─ rt_mutex_init(&mutex_oled, "m_oled", RT_IPC_FLAG_FIFO)
 │   ├─ rt_semaphore_init(&sem_sensor, "s_sensor", 0, RT_IPC_FLAG_FIFO)
 │   ├─ rt_semaphore_init(&sem_key, "s_key", 0, RT_IPC_FLAG_FIFO)
 │   ├─ rt_semaphore_init(&sem_wifi_rx, "s_wifi", 0, RT_IPC_FLAG_FIFO)
 │   └─ rt_mb_init(&mb_alarm, "mb_alarm", &alarm_buf, 8, RT_IPC_FLAG_FIFO)
 │
 ├─ 5. 创建业务线程
 │   ├─ rt_thread_create("t_sensor", ...)  → rt_thread_startup
 │   ├─ rt_thread_create("t_control", ...) → rt_thread_startup
 │   ├─ rt_thread_create("t_display", ...) → rt_thread_startup
 │   ├─ rt_thread_create("t_key", ...)     → rt_thread_startup
 │   ├─ rt_thread_create("t_alarm", ...)   → rt_thread_startup
 │   ├─ rt_thread_create("t_feed", ...)    → rt_thread_startup
 │   └─ rt_thread_create("t_wifi", ...)    → rt_thread_startup
 │
 ├─ 6. 显示启动画面
 │   ├─ OLED_ShowStart()          # 显示"智能鱼缸系统"
 │   └─ rt_thread_mdelay(2000)    # 停留2秒（让出CPU）
 │
 ├─ 7. 进入主页面
 │   └─ OLED_ShowMainPage()
 │
 └─ main 线程结束（或进入空闲循环）
```

## 6. 关键代码示例

### 6.1 main.c — 主线程入口

```c
#include <rtthread.h>
#include <rtdbg.h>
#include "app_data.h"
#include "app_sensor.h"
#include "app_control.h"
#include "app_display.h"
#include "app_key.h"
#include "app_alarm.h"
#include "app_feed.h"
#include "app_wifi.h"

/* 全局数据 */
struct rt_mutex mutex_data;
struct rt_mutex mutex_oled;
struct rt_semaphore sem_sensor;
struct rt_semaphore sem_key;
struct rt_semaphore sem_wifi_rx;
struct rt_mailbox mb_alarm;
static rt_uint32_t alarm_buf[8];

int main(void)
{
    /* 1. 外设初始化 */
    oled_init();
    ds18b20_init();
    adc_init();
    relay_init();
    servo_init();
    wifi_init();

    /* 2. 加载默认阈值 */
    sysflag_init();
    fish_tank_flag.run_mode = MODE_AUTO;
    fish_tank_flag.alarm_enable = 1;
    fish_tank_feed.countdown = fish_tank_set.feed_interval;

    /* 3. WiFi 连接（失败离线模式） */
    if (wifi_connect() != RT_EOK)
    {
        LOG_W("WiFi connect failed, enter offline mode");
    }

    /* 4. 创建 IPC 对象 */
    rt_mutex_init(&mutex_data, "m_data", RT_IPC_FLAG_FIFO);
    rt_mutex_init(&mutex_oled, "m_oled", RT_IPC_FLAG_FIFO);
    rt_semaphore_init(&sem_sensor, "s_sensor", 0, RT_IPC_FLAG_FIFO);
    rt_semaphore_init(&sem_key, "s_key", 0, RT_IPC_FLAG_FIFO);
    rt_semaphore_init(&sem_wifi_rx, "s_wifi", 0, RT_IPC_FLAG_FIFO);
    rt_mb_init(&mb_alarm, "mb_alarm", &alarm_buf[0], 8, RT_IPC_FLAG_FIFO);

    /* 5. 创建业务线程 */
    rt_thread_t tid;

    tid = rt_thread_create("t_sensor", sensor_thread_entry, RT_NULL, 1024, 15, 10);
    if (tid) rt_thread_startup(tid);

    tid = rt_thread_create("t_control", control_thread_entry, RT_NULL, 1024, 12, 10);
    if (tid) rt_thread_startup(tid);

    tid = rt_thread_create("t_display", display_thread_entry, RT_NULL, 1024, 18, 10);
    if (tid) rt_thread_startup(tid);

    tid = rt_thread_create("t_key", key_thread_entry, RT_NULL, 512, 14, 10);
    if (tid) rt_thread_startup(tid);

    tid = rt_thread_create("t_alarm", alarm_thread_entry, RT_NULL, 512, 13, 10);
    if (tid) rt_thread_startup(tid);

    tid = rt_thread_create("t_feed", feed_thread_entry, RT_NULL, 512, 16, 10);
    if (tid) rt_thread_startup(tid);

    tid = rt_thread_create("t_wifi", wifi_thread_entry, RT_NULL, 2048, 17, 10);
    if (tid) rt_thread_startup(tid);

    /* 6. 显示启动画面 */
    rt_mutex_take(&mutex_oled, RT_WAITING_FOREVER);
    oled_show_start();
    rt_mutex_release(&mutex_oled);
    rt_thread_mdelay(2000);

    /* 7. 进入主页面 */
    rt_mutex_take(&mutex_oled, RT_WAITING_FOREVER);
    oled_show_main_page();
    rt_mutex_release(&mutex_oled);

    return RT_EOK;
}
```

### 6.2 传感器采集线程 (app_sensor.c)

```c
static void sensor_thread_entry(void *param)
{
    while (1)
    {
        rt_mutex_take(&mutex_data, RT_WAITING_FOREVER);

        /* DS18B20 温度采集 */
        fish_tank_data.water_temp = ds18b20_read_temp();

        /* ADC 多通道采集 */
        fish_tank_data.air_quality = adc_read_air();        /* PA4, 原始值 */
        fish_tank_data.water_level = adc_read_water_level(); /* PA1, 百分比 */
        fish_tank_data.ph_value = adc_read_ph();            /* PA0, PH值 */

        rt_mutex_release(&mutex_data);

        /* 通知控制线程和报警线程 */
        rt_semaphore_release(&sem_sensor);

        rt_thread_mdelay(500);
    }
}
```

### 6.3 自动控制线程 (app_control.c)

```c
static void control_thread_entry(void *param)
{
    while (1)
    {
        /* 等待传感器数据就绪 */
        rt_semaphore_take(&sem_sensor, RT_WAITING_FOREVER);

        if (fish_tank_flag.run_mode == MODE_AUTO)
        {
            rt_mutex_take(&mutex_data, RT_WAITING_FOREVER);
            float temp = fish_tank_data.water_temp;
            uint8_t level = fish_tank_data.water_level;
            uint16_t air = fish_tank_data.air_quality;
            rt_mutex_release(&mutex_data);

            /* 温度控制 — 滞环 */
            if (temp < fish_tank_set.temp_lower)
                relay_heat_on();
            else if (temp > fish_tank_set.temp_upper)
                relay_heat_off();

            /* 水位控制 */
            if (level > fish_tank_set.water_level_max)
            {
                relay_fill_off();
                relay_drain_on();
            }
            else if (level < fish_tank_set.water_level_min)
            {
                relay_drain_off();
                relay_fill_on();
            }
            else
            {
                relay_drain_off();
                relay_fill_off();
            }

            /* 空气质量控制 */
            if (air > fish_tank_set.air_quality_max)
                relay_oxygen_on();
            else
                relay_oxygen_off();

            /* 报警事件发送到邮箱 */
            if (check_alarm_condition())
            {
                rt_uint32_t evt = ALARM_EVENT_ACTIVE;
                rt_mb_send(&mb_alarm, evt);
            }
        }

        rt_thread_mdelay(500);
    }
}
```

### 6.4 报警处理线程 (app_alarm.c)

```c
static void alarm_thread_entry(void *param)
{
    rt_uint32_t alarm_event;
    while (1)
    {
        if (rt_mb_recv(&mb_alarm, &alarm_event, RT_WAITING_FOREVER) == RT_EOK)
        {
            if (!fish_tank_flag.alarm_enable)
                continue;

            /* 响 0.5s 停 2s 循环报警 */
            beep_on();
            led_on();
            rt_thread_mdelay(500);
            beep_off();
            led_off();
            rt_thread_mdelay(2000);
        }
    }
}
```

### 6.5 按键扫描线程 (app_key.c)

```c
static void key_thread_entry(void *param)
{
    while (1)
    {
        /* 等待按键中断通知 */
        if (rt_semaphore_take(&sem_key, rt_tick_from_millisecond(50)) == RT_EOK)
        {
            key_scan();          /* 物理消抖 + 事件检测 */
            key_event_process(); /* 页面切换/模式/阈值调整 */
        }
    }
}
```

```c
{

    {
        rt_mutex_take(&mutex_data, RT_WAITING_FOREVER);
        fish_tank_data.water_temp = ds18b20_read_temp();
        fish_tank_data.water_level = adc_read_water_level();
        fish_tank_data.ph_value = adc_read_ph();
        fish_tank_data.air_quality = adc_read_air();
        rt_mutex_release(&mutex_data);
        rt_semaphore_release(&sem_sensor);
        rt_thread_mdelay(500);
    }
}

/* app_control.c */
static void control_thread_entry(void *param)
{
    while (1)
    {
        rt_semaphore_take(&sem_sensor, RT_WAITING_FOREVER);
        if (fish_tank_flag.run_mode == MODE_AUTO)
            auto_control();
        rt_thread_mdelay(500);
    }
}

/* app_display.c */
static void display_thread_entry(void *param)
{
    while (1)
    {
        rt_mutex_take(&mutex_oled, RT_WAITING_FOREVER);
        oled_refresh();
        rt_mutex_release(&mutex_oled);
        rt_thread_mdelay(1000);
    }
}

/* app_key.c */
static void key_thread_entry(void *param)
{
    while (1)
    {
        if (rt_semaphore_take(&sem_key, rt_tick_from_millisecond(50)) == RT_EOK)
            key_event_process();
    }
}

/* app_alarm.c */
static void alarm_thread_entry(void *param)
{
    rt_uint32_t evt;
    while (1)
    {
        if (rt_mb_recv(&mb_alarm, &evt, RT_WAITING_FOREVER) == RT_EOK)
        {
            beep_on(); led_on();
            rt_thread_mdelay(500);
            beep_off(); led_off();
            rt_thread_mdelay(2000);
        }
    }
}

/* app_feed.c */
static void feed_thread_entry(void *param)
{
    while (1)
    {
        feed_process();
        rt_thread_mdelay(1000);
    }
}

/* app_wifi.c */
static void wifi_thread_entry(void *param)
{
    while (1)
    {
        rt_semaphore_take(&sem_wifi_rx, RT_WAITING_FOREVER);
        wifi_rx_process();
    }
}
```

## 8. 业务逻辑流程

> 业务逻辑不变，仅技术实现从中断回调迁移到线程

### 8.1 页面导航状态机

> 对应需求规格书 §3 按键功能定义 + §4 OLED 显示页面

```
              KEY1                    KEY1
  ┌──────────────────────┐  ┌──────────────────────┐
  │                      ▼  │                      ▼
┌──────┐  KEY1  ┌──────────┐  KEY2  ┌──────────┐
│ 主页 │ ─────→ │ 自动设置  │ ─────→ │ 手动控制  │
│ (P0) │        │  (P1)    │        │  (P2)    │
└──┬───┘        └────┬─────┘        └────┬─────┘
   │                 │                    │
   │ KEY2            │ KEY1/KEY2         │ KEY2
   └─────────────────┘←──────────────────┘
```

- **KEY1 (PA8)**：设置页/手动页返回主页
- **KEY2 (PB3)**：任何页面循环切换 P0→P1→P2→P0
- **全局变量** `CurrentPage` 维护当前页面（0/1/2），由 mutex_data 保护

### 8.2 按键功能矩阵

> 对应需求规格书 §3.1

| 按键 | 主页 (P0) | 自动设置 (P1) | 手动控制 (P2) |
|------|-----------|---------------|---------------|
| KEY1 | 进入设置 | 返回主页 | 返回主页 |
| KEY2 | 切下一页 | 选下一项 | 选下一项 |
| KEY3 | 切手/自动 | 阈值 +1 | 设备开/关 |
| KEY4 | — | 阈值 -1 | — |
| KEY5 | 长按2s 喂食 | — | — |

### 8.3 自动控制逻辑

> 对应需求规格书 §5.3，逻辑不变，由 t_control 线程每 500ms 执行

```
Auto_Control() [t_control 线程，仅自动模式]

  温度控制：
    if(WaterTemp < TempLower) → 开加热(Relay_HEAT=ON)
    if(WaterTemp > TempUpper) → 关加热(Relay_HEAT=OFF)
    else → 维持当前状态（滞环控制）

  水位控制：
    if(WaterLevel > WaterLevel_Max) → 开排水(Relay_DRAIN=ON), 关加水
    if(WaterLevel < WaterLevel_Min) → 开加水(Relay_FILL=ON), 关排水
    else → 两个继电器均关闭（安全区间）

  空气质量控制：
    if(AirQuality > AirQuality_Max) → 开增氧(Relay_OXYGEN=ON)
    else → 关增氧(Relay_OXYGEN=OFF)
```

### 8.4 报警逻辑

> 对应需求规格书 §5.4，逻辑不变，由 t_alarm 线程通过邮箱事件驱动

```
t_alarm 线程 [邮箱阻塞等待]

  if(!Alarm_Enable) → 跳过

  rt_mb_recv(&mb_alarm, ...) 阻塞等待报警事件

  收到事件后执行声光报警：
    响 0.5s → 停 2s → 循环
    直到报警条件解除（由 t_control 不再发送事件）
```

### 8.5 喂食控制

> 对应需求规格书 §5.3 F-CTL-004，逻辑不变，由 t_feed 线程每 1s 执行

```
Feed_Process() [t_feed 线程]

  ┌─ 手动触发(KEY5长按/手动页) → Feed_Trigger=1
  │
  ├─ if(Feed_Trigger && !Feeding)
  │     → Servo_SetAngle(90), Servo_Timer=0, Feeding=1
  │
  ├─ if(Countdown > 0)
  │     → Countdown--
  │     if(Countdown == 0 && !Feeding)
  │       → Servo_SetAngle(90), Servo_Timer=0, Feeding=1
  │
  └─ if(Servo_Open)
        → Servo_Timer++
        if(Servo_Timer >= 3)
          → Servo_Off(), Feeding=0, 重置Countdown=FeedInterval
```

### 8.6 模式切换

> 对应需求规格书 §5.5，逻辑不变，由 t_key 线程处理

```
自动→手动 (RunMode: 0→1):
  1. Relay_AllOff()          ← 关闭所有继电器
  2. 手动开关标志全部清零
  3. RunMode = 1

手动→自动 (RunMode: 1→0):
  1. Relay_AllOff()          ← 关闭所有继电器
  2. 手动开关标志全部清零
  3. RunMode = 0
  4. t_control 线程自动接管控制
```

### 8.7 传感器采集

> 对应需求规格书 §5.1，由 t_sensor 线程每 500ms 执行

```
t_sensor 线程:

  rt_mutex_take(&mutex_data)
  ├─ DS18B20_ReadTemp() → WaterTemp     (float 摄氏度)
  ├─ ADC Channel 4 (PA4) → AirQuality   (原始值 0~4095)
  ├─ ADC Channel 1 (PA1) → WaterLevel   (×100/4095 → 百分比)
  └─ ADC Channel 0 (PA0) → PH_Value     (×14.0/4095 → PH值)
  rt_mutex_release(&mutex_data)

  rt_semaphore_release(&sem_sensor)     ← 通知控制/报警线程
```
