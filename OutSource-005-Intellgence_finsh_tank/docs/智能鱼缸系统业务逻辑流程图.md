## 1. 系统启动流程 (RT-Thread 版)

```
┌─────────────────────────┐
│        上电/复位          │
└────────────┬────────────┘
             ▼
┌─────────────────────────────────────────────┐
│  RT-Thread 内核初始化                        │
│  ├─ SystemClock_Config()    (72MHz)         │
│  ├─ rt_hw_interrupt_init()  (中断向量表)     │
│  ├─ rt_system_tick_init()   (系统节拍)       │
│  ├─ rt_system_heap_init()   (堆内存)         │
│  ├─ rt_system_scheduler_init() (调度器)      │
│  └─ rt_system_timer_init()  (系统定时器)     │
└────────────┬────────────────────────────────┘
             ▼
┌─────────────────────────────────────────────┐
│  组件初始化                                   │
│  ├─ finsh_system_init()     (FinSH 命令行)   │
│  └─ rt_device_driver_register() (设备框架)   │
└────────────┬────────────────────────────────┘
             ▼
┌─────────────────────────────────────────────┐
│  main() 线程 (优先级10, 栈2048)              │
│                                             │
│  [1] 外设初始化                              │
│      ├─ oled_init()        (PA12/PA11 I2C)  │
│      ├─ ds18b20_init()     (PB13 1-Wire)    │
│      ├─ adc_init()         (PA0/PA1/PA4)    │
│      ├─ relay_init()       (4路继电器)       │
│      ├─ servo_init()       (PA6 TIM3 PWM)   │
│      └─ wifi_init()        (PA2/PA3 USART2) │
└────────────┬────────────────────────────────┘
             ▼
┌─────────────────────────────────────────────┐
│  [2] 加载默认阈值                             │
│      ├─ SysFlag_Init()                      │
│      ├─ RunMode = 0 (自动)                   │
│      ├─ Alarm_Enable = 1                     │
│      └─ Countdown = FeedInterval             │
└────────────┬────────────────────────────────┘
             ▼
┌─────────────────────────────────────────────┐
│  [3] WiFi 连接                               │
│      ├─ 成功 → 在线模式                       │
│      └─ 失败 → 离线模式 (RunMode=0)          │
└────────────┬────────────────────────────────┘
             ▼
┌─────────────────────────────────────────────┐
│  [4] 创建 IPC 对象                           │
│      ├─ rt_mutex_init(&mutex_data)           │
│      ├─ rt_mutex_init(&mutex_oled)           │
│      ├─ rt_semaphore_init(&sem_sensor)       │
│      ├─ rt_semaphore_init(&sem_key)          │
│      ├─ rt_semaphore_init(&sem_wifi_rx)      │
│      └─ rt_mb_init(&mb_alarm)               │
└────────────┬────────────────────────────────┘
             ▼
┌─────────────────────────────────────────────┐
│  [5] 创建业务线程 (全部 rt_thread_startup)    │
│      ├─ t_sensor  (优先级15, 栈1024)         │
│      ├─ t_control (优先级12, 栈1024)         │
│      ├─ t_display (优先级18, 栈1024)         │
│      ├─ t_key     (优先级14, 栈512)          │
│      ├─ t_alarm   (优先级13, 栈512)          │
│      ├─ t_feed    (优先级16, 栈512)          │
│      └─ t_wifi    (优先级17, 栈2048)         │
└────────────┬────────────────────────────────┘
             ▼
┌─────────────────────────────────────────────┐
│  [6] 显示启动画面                            │
│      ├─ OLED_ShowStart()  "智能鱼缸系统"     │
│      └─ rt_thread_mdelay(2000)  (让出CPU)    │
└────────────┬────────────────────────────────┘
             ▼
┌─────────────────────────────────────────────┐
│  [7] OLED_ShowMainPage()  进入主页面          │
└────────────┬────────────────────────────────┘
             ▼
┌─────────────────────────────────────────────┐
│  main 线程结束                               │
│  各业务线程由 RT-Thread 调度器接管运行         │
└─────────────────────────────────────────────┘
```

**与裸机启动的关键差异**：
- 裸机 `while(1){}` 主循环 + TIM2 中断调度 → RT-Thread 多线程并行调度
- 裸机 `delay_ms(2000)` 忙等 → `rt_thread_mdelay(2000)` 让出 CPU
- 裸机 `NVIC_PriorityGroup` → RT-Thread `rt_hw_interrupt_init()` 统一管理

## 2. 线程调度与 IPC 通信流程

### 2.1 线程调度时序（替代原 TIM2 中断调度）

```
RT-Thread 调度器（优先级抢占式调度）

  优先级
   12 ───────── t_control ──────────────── 自动控制 (500ms周期)
   13 ───────── t_alarm ──────────────── 报警处理 (邮箱阻塞)
   14 ───────── t_key ──────────────── 按键扫描 (50ms周期)
   15 ───────── t_sensor ──────────────── 传感器采集 (500ms周期)
   16 ───────── t_feed ──────────────── 喂食控制 (1s周期)
   17 ───────── t_wifi ──────────────── WiFi通信 (事件驱动)
   18 ───────── t_display ──────────────── OLED刷新 (1s周期)

  高优先级线程可抢占低优先级线程
  同优先级线程按时间片轮转 (tick=10)
```

### 2.2 IPC 通信数据流

```
                    ┌──────────┐
    外部中断 ──────→│ sem_key  │──────→ t_key (按键处理)
                    └──────────┘

                    ┌──────────────┐
    串口RX中断 ────→│ sem_wifi_rx │──────→ t_wifi (WiFi处理)
                    └──────────────┘

                    ┌─────────────┐
    t_sensor ─────→│ sem_sensor  │──────→ t_control (自动控制)
                    └─────────────┘         t_alarm (报警判断)

                    ┌──────────────┐
    t_control ────→│  mb_alarm   │──────→ t_alarm (声光报警)
                    └──────────────┘

    ┌─────────────┐  互斥保护  ┌──────────────┐
    │ t_sensor    │◄─────────►│ mutex_data   │
    │ t_control   │           │ (传感器数据)  │
    │ t_alarm     │           └──────────────┘
    │ t_display   │
    │ t_feed      │
    └─────────────┘

    ┌─────────────┐  互斥保护  ┌──────────────┐
    │ t_display   │◄─────────►│ mutex_oled   │
    │ t_key       │           │ (OLED资源)   │
    └─────────────┘           └──────────────┘
```

## 3. 自动控制流程 (t_control 线程 - 每500ms)

```
t_control 线程入口
│
├── rt_semaphore_take(&sem_sensor, ...)  # 等待传感器数据就绪
│
├── rt_mutex_take(&mutex_data)           # 加锁读取传感器数据
│   ├── temp = fish_tank_data.water_temp
│   ├── level = fish_tank_data.water_level
│   └── air = fish_tank_data.air_quality
├── rt_mutex_release(&mutex_data)        # 解锁
│
├── if(RunMode != 0) rt_thread_mdelay(500); continue  # 非自动模式跳过
│
├── [温度控制]
│   ├── temp < TempLower ?
│   │   └── YES → relay_heat_on() (加热)
│   ├── temp > TempUpper ?
│   │   └── YES → relay_heat_off()
│   └── 在上下限之间 → 维持当前状态 (滞环)
│
├── [水位控制]
│   ├── level > WaterLevel_Max ?
│   │   ├── YES → relay_fill_off()
│   │   └── YES → relay_drain_on() (排水)
│   ├── level < WaterLevel_Min ?
│   │   ├── YES → relay_drain_off()
│   │   └── YES → relay_fill_on() (加水)
│   └── 在安全区间 → relay_drain_off(), relay_fill_off()
│
├── [空气质量控制]
│   ├── air > AirQuality_Max ?
│   │   └── YES → relay_oxygen_on() (增氧)
│   └── NO → relay_oxygen_off()
│
├── [报警事件检测]
│   └── if(任一报警条件激活)
│       └── rt_mb_send(&mb_alarm, ALARM_EVENT_ACTIVE)
│
└── rt_thread_mdelay(500)
```

**温度滞环示意**（不变）：
```
        TempUpper ──────── Relay_HEAT = OFF
             │
             │   安全区间 (维持当前状态)
             │
        TempLower ──────── Relay_HEAT = ON
```

**水位区间示意**（不变）：
```
        100% ─────
             │
        Max ──────── 开始排水 (Relay_DRAIN=ON)
             │
             │   安全区间 (两继电器均OFF)
             │
        Min ──────── 开始加水 (Relay_FILL=ON)
             │
         0% ─────
```

## 4. 报警逻辑流程 (t_alarm 线程 - 邮箱事件驱动)

```
t_alarm 线程入口
│
├── if(!Alarm_Enable)
│   └── rt_thread_mdelay(500); continue    # 报警关闭, 跳过
│
├── rt_mb_recv(&mb_alarm, &alarm_event, RT_WAITING_FOREVER)
│   # 阻塞等待报警事件（由 t_control 发送）
│
├── 收到 ALARM_EVENT_ACTIVE:
│   ├── beep_on(); led_on()
│   ├── rt_thread_mdelay(500)              # 响 0.5s
│   ├── beep_off(); led_off()
│   └── rt_thread_mdelay(2000)             # 停 2s
│       # 然后循环回到 rt_mb_recv 等待下一个事件
│
报警解除: t_control 不再发送事件 → t_alarm 阻塞等待 → 蜂鸣器/LED 静默
```

**与裸机的关键差异**：
- 裸机：TIM2 500ms 中断中轮询报警标志 → RT-Thread：邮箱事件驱动，无事件时阻塞不占 CPU
- 裸机：BEEP_DrvScan 1ms 状态机 → RT-Thread：线程 rt_thread_mdelay 控制响停时序

## 5. 喂食控制流程 (t_feed 线程 - 每1s)

```
t_feed 线程入口
│
├── [手动触发检查]
│   ├── if(Feed_Trigger)
│   │   ├── Feed_Trigger = 0 (清标志)
│   │   ├── if(!Feeding)
│   │   │   ├── Feeding = 1
│   │   │   ├── Servo_Open = 1
│   │   │   ├── Servo_Timer = 0
│   │   │   └── servo_set_angle(90)    ← 舵机打开
│
├── [倒计时递减]
│   ├── if(Countdown > 0)
│   │   ├── Countdown--
│   │   └── if(Countdown == 0 && !Feeding)
│   │       ├── Feeding = 1, Servo_Open = 1
│   │       ├── Servo_Timer = 0
│   │       └── servo_set_angle(90)    ← 倒计时归零触发
│
├── [舵机超时关闭]
│   ├── if(Servo_Open)
│   │   ├── Servo_Timer++
│   │   └── if(Servo_Timer >= 3)       ← 3秒后
│   │       ├── servo_off()            ← 舵机关闭
│   │       ├── Servo_Open = 0
│   │       ├── Feeding = 0
│   │       └── Countdown = FeedInterval  ← 重置倒计时
│
└── rt_thread_mdelay(1000)
```

**喂食状态机**（不变）：
```
  ┌──────────┐  触发   ┌──────────┐  3秒后  ┌──────────┐
  │  待机     │ ─────→ │ 舵机打开  │ ─────→ │ 舵机关闭  │
  │ Countdown │        │ Servo_Open│        │ 重置倒计时│
  └──────────┘        └──────────┘        └──────────┘
```

## 6. 按键业务流程 (t_key 线程)

### 6.1 按键扫描机制（替代原 TIM2 1ms 中断扫描）

```
t_key 线程入口
│
├── rt_semaphore_take(&sem_key, rt_tick_from_millisecond(50))
│   # 有按键中断 → 立即响应
│   # 无按键中断 → 50ms 超时后继续扫描
│
├── key_scan()
│   ├── 读取 GPIO 电平
│   ├── 消抖处理 (连续5次一致确认)
│   ├── 短按/长按2s/长按4s 检测
│   └── 写入事件队列
│
├── key_event_process()
│   ├── 页面导航 (KEY1/KEY2)
│   ├── 模式切换 (KEY3 主页)
│   ├── 阈值调整 (KEY3/KEY4 设置页)
│   ├── 设备开关 (KEY3 手动页)
│   └── 喂食触发 (KEY5 长按2s)
│
└── 循环回到 semaphore_take
```

### 6.2 页面导航状态机（不变）

```
        ┌─────────────────────────────────────┐
        │              主页 (P0)              │
        │  温度 空气  水位 PH  模式 喂食 状态 │
        └──┬──────────────────────────────┬───┘
    KEY1 ↓                          KEY2 ↓
  ┌──────────────────┐     ┌──────────────────┐
  │  自动设置 (P1)   │     │  手动控制 (P2)   │
  │  温Lo/Hi 空气    │     │  加热/加水/排水   │
  │  PH Lo/Hi 水位   │     │  增氧/报警/喂食   │
  │  喂食间隔        │     │                  │
  └──┬───────────┬───┘     └──┬───────────┬───┘
 KEY1↓      KEY2↓          KEY1↓      KEY2↓
     └──→ 主页 ←──────────────┘          │
                                         ↓
                                    ┌────────┐
                                    │  主页   │
                                    └────────┘
```

### 6.3 按键功能矩阵（不变）

| 按键 | 事件 | 主页 (P0) | 自动设置 (P1) | 手动控制 (P2) |
|------|------|-----------|---------------|---------------|
| KEY1 (PA8) | 短按 | → 进入设置页 | → 返回主页 | → 返回主页 |
| KEY2 (PB3) | 短按 | P0→P1→P2→P0 | 选中项下移 (循环) | 选中项下移 (循环) |
| KEY3 (PB4) | 短按 | 切换手/自动 | 当前项 +1 | 当前设备 开/关 |
| KEY4 (PB8) | 短按 | — | 当前项 -1 | — |
| KEY5 (PB1) | 长按2s | 触发喂食 | — | — |

### 6.4 模式切换流程（不变）

```
KEY3 在主页按下:
│
├── 当前 RunMode == 0 (自动)?
│   └── YES
│       ├── Relay_AllOff()                    # 关闭所有继电器
│       ├── Relay_*_Manual 全部清零
│       └── RunMode = 1                       # 切换到手动
│
└── 当前 RunMode == 1 (手动)?
    └── YES
        ├── Relay_AllOff()                    # 关闭所有继电器
        ├── Relay_*_Manual 全部清零
        └── RunMode = 0                       # 切换到自动
            (t_control 线程自动接管)
```

### 6.5 自动设置页操作流程（不变）

```
7个设置项: 索引 0~6
┌──────────┬──────────────────┬───────┬───────┐
│  索引    │     参数         │ KEY3加 │ KEY4减 │
├──────────┼──────────────────┼───────┼───────┤
│  0       │ 温度下限 (°C)    │ +1.0  │ -1.0  │
│  1       │ 温度上限 (°C)    │ +1.0  │ -1.0  │
│  2       │ 空气质量阈值     │ +10   │ -10   │
│  3       │ PH 下限          │ +0.5  │ -0.5  │
│  4       │ PH 上限          │ +0.5  │ -0.5  │
│  5       │ 水位下限 (%)     │ +5    │ -5    │
│  6       │ 喂食间隔 (秒)    │ +60   │ -60   │
└──────────┴──────────────────┴───────┴───────┘

KEY2 短按 → AutoSet_Index = (Index+1) % 7 (循环选中)
选中项中文字符反显 (inv=1)
```

### 6.6 手动控制页操作流程（不变）

```
6个控制项: 索引 0~5
┌──────────┬──────────────────┬──────────────┐
│  索引    │     设备         │   KEY3操作    │
├──────────┼──────────────────┼──────────────┤
│  0       │ 加热 (PB12)      │ 开/关切换    │
│  1       │ 加水 (PB14)      │ 开/关切换    │
│  2       │ 排水 (PB15)      │ 开/关切换    │
│  3       │ 增氧 (PA15)      │ 开/关切换    │
│  4       │ 报警             │ 使能/禁用    │
│  5       │ 喂食             │ 触发一次     │
└──────────┴──────────────────┴──────────────┘

KEY2 短按 → ManualSet_Index = (Index+1) % 6 (循环选中)
选中项中文字符反显 (inv=1)
```

## 7. 传感器采集流程 (t_sensor 线程 - 每500ms)

```
t_sensor 线程入口
│
├── rt_mutex_take(&mutex_data, RT_WAITING_FOREVER)
│
├── DS18B20 温度采集
│   └── fish_tank_data.water_temp = ds18b20_read_temp()
│       # rt_device 框架封装 1-Wire 时序
│
├── ADC 空气质量 (PA4, ADC1_IN4)
│   └── fish_tank_data.air_quality = adc_read_air()
│       # rt_device ADC 框架, 原始值 0~4095
│
├── ADC 水位 (PA1, ADC1_IN1)
│   └── fish_tank_data.water_level = adc_read_water_level()
│       # ADC×100/4095 → 百分比 0~100%
│
├── ADC PH值 (PA0, ADC1_IN0)
│   └── fish_tank_data.ph_value = adc_read_ph()
│       # ADC×14.0/4095.0 → PH值 0~14
│
├── rt_mutex_release(&mutex_data)
│
├── rt_semaphore_release(&sem_sensor)     # 通知 t_control 和 t_alarm
│
└── rt_thread_mdelay(500)
```

**与裸机采集的关键差异**：
- 裸机：TIM2 10ms 中断轮询 3 个 ADC 通道（轮流采集） → RT-Thread：500ms 周期一次性采集全部通道
- 裸机：ADC 寄存器直接操作 → RT-Thread：rt_device ADC 框架统一接口
- 裸机：全局变量直接写入 → RT-Thread：mutex_data 保护下写入

## 8. OLED 页面刷新流程 (t_display 线程 - 每1s)

```
t_display 线程入口
│
├── rt_mutex_take(&mutex_oled, RT_WAITING_FOREVER)   # 获取 OLED 资源
│
├── switch(CurrentPage)
│   ├── case 0: oled_show_main_page()
│   │   ├── 温度 + 空气质量
│   │   ├── 水位 + PH值
│   │   ├── 模式(自/手) + 喂食倒计时
│   │   └── 继电器状态: 热+氧-排-加-
│   │
│   ├── case 1: oled_show_auto_set_page()
│   │   ├── 屏1 (Index 0-3): 温Lo/温Hi/空气/PH Lo
│   │   └── 屏2 (Index 4-6): PH Hi/水位/喂食间隔
│   │
│   └── case 2: oled_show_manual_page()
│       ├── 屏1 (Index 0-3): 加热/加水/排水/增氧
│       └── 屏2 (Index 4-5): 报警/喂食
│
├── rt_mutex_release(&mutex_oled)                    # 释放 OLED 资源
│
└── rt_thread_mdelay(1000)
```

**与裸机刷新的关键差异**：
- 裸机：TIM2 1s 中断中直接调用 OLED 函数 → RT-Thread：独立线程 + mutex_oled 互斥保护
- 裸机：中断中执行 I2C 通信（阻塞风险） → RT-Thread：线程中安全执行

## 9. WiFi 通信流程 (t_wifi 线程 - 事件驱动)

```
t_wifi 线程入口
│
├── rt_semaphore_take(&sem_wifi_rx, RT_WAITING_FOREVER)
│   # 阻塞等待串口 RX 中断通知
│
├── wifi_rx_process()
│   ├── 解析 AT 指令响应
│   ├── 更新远程控制参数
│   └── 发送传感器数据上报
│
└── 循环回到 semaphore_take
```

**与裸机 WiFi 的关键差异**：
- 裸机：USART 中断回调中直接处理 → RT-Thread：中断只释放信号量，业务在线程中处理
- 裸机：中断中执行字符串解析（风险高） → RT-Thread：线程中安全解析
